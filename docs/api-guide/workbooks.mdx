## 📓 Workbooks

Workbooks are interactive documents within a Workspace where you can perform data analysis, visualization, and modeling. You can create multiple workbooks to organize different projects or analyses.

### Create Table in Workspace

<div className="endpoint-card">
  <div className="endpoint-header">
    <span className="method-badge method-post">POST</span>
    <code className="endpoint-url">/noCo/api/v2/workspaces/:workspaceId/tables</code>
  </div>
  
  <div className="endpoint-body">
    <p>Initializes a new table within a specific workspace. You can optionally include columns in the same request.</p>
    
    <h4>Query Parameters</h4>
    <ul>

    ```bash
    curl --location 'https://{{base_url}}/noCo/api/v2/workspaces/{{workspace_id}}/tables?isIncludeColumns=true' \
    --header 'x-auth-token: {{token}}'
    ```

  </div>
</div>

      </thead>
      <tbody>
        <tr>

          <td>object</td>
          <td>Yes</td>
          <td>Pagination settings (pageNumber, pageSize)</td>
          <td><code>{'{"pageNumber": 1, "pageSize": 50}'}</code></td>
        </tr>
        <tr>
          <td><code>whereClause</code></td>

          <td>array</td>

          <td>List of sorting rules</td>
          <td><code>{'[{"columnName": "name", "direction": "ASC"}]'}</code></td>
        </tr>
      </tbody>
    </table>

    <div className="playground-section">
      <h4>Try it out</h4>
      <ApiPlayground
        method="POST"
        endpoint="/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/data/external"

        }}

### 📊 Column Data Types

When creating columns, use the following `uiDataType` values to define the behavior and validation of your data.

| `uiDataType`       | Description                         | Example Value                     |
| :----------------- | :---------------------------------- | :-------------------------------- |
| `SINGLE_LINE_TEXT` | Short text values.                  | `"Jane Doe"`                      |
| `LONG_TEXT`        | Multi-line text or descriptions.    | `"This is a long description..."` |
| `NUMBER`           | Numeric values (integer/decimal).   | `1250.50`                         |
| `DATE`             | Calendar dates.                     | `"2025-12-31"`                    |
| `CHECKBOX`         | Boolean true/false values.          | `true`                            |
| `FORMULA`          | Calculated values using SQL syntax. | `price * quantity`                |
| `SINGLE_SELECT`    | One value from a predefined list.   | `"Active"`                        |

    ```json
            "title": "Contact Name"

        "name": "contact_name"
    }
    ```

    </TabItem>
    <TabItem value="formula" label="Formula Column">

    ```json
    {
        "uiDataType": "FORMULA",
        "uiMetadata": {
            "title": "Description Length"
        },
        "formula": "length(description)",
        "formulaType": "SQL",
        "name": "desc_length"
    }
    ```

    </TabItem>
    <TabItem value="ai" label="AI Generated Column">

    ```json
    {
        "uiDataType": "SINGLE_LINE_TEXT",
        "name": "ai_summary",
        "description": "Auto-generated summary",
        "uiMetadata": {
            "title": "AI Summary"
        },
        "required": false,
        "settings": {
            "aiSettings": {
                "enabled": true,
                "prompt": "Summarize the 'description' field in 10 words",
                "model": "gpt-4o-mini",
                "webAccess": false
            }
        }
    }
    ```

    </TabItem>
    </Tabs>

  </div>
</div>

### Update Column

<div className="endpoint-card">
  <div className="endpoint-header">
    <span className="method-badge method-put">PUT</span>
    <code className="endpoint-url">/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/columns/:columnId</code>
  </div>
  
  <div className="endpoint-body">
    <p>Updates an existing column's definition, such as its title, description, or data type settings.</p>

    <h4>Request Body (JSON)</h4>
    ```json
    {
        "name": "updated_column_name",
        "uiDataType": "SINGLE_LINE_TEXT",
        "uiMetadata": {
            "title": "New Column Title"
        }
    }
    ```

    <div className="playground-section">
      <h4>Try it out</h4>
      <ApiPlayground
        method="PUT"
        endpoint="/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/columns/:columnId"
        defaultBody={{
          name: "question",
          uiDataType: "SINGLE_LINE_TEXT",
          uiMetadata: { title: "Updated Question Title" }
        }}
        successResponse={{
          id: "col_12345",
          name: "question",
          status: "UPDATED"
        }}
      />
    </div>

  </div>
</div>
