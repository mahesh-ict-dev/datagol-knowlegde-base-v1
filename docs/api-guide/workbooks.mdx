## 📓 Workbooks

Workbooks are interactive documents within a Workspace where you can perform data analysis, visualization, and modeling. You can create multiple workbooks to organize different projects or analyses.

### Create Table in Workspace

<div className="endpoint-card">
  <div className="endpoint-header">

    <code className="endpoint-url">https://be.datagol.ai/noCo/api/v2/workspaces/:workspaceId/tables</code>
  </div>
  
  <div className="endpoint-body">

</div>

### Get Table Data

<div className="endpoint-card">
  <div className="endpoint-header">
    <span className="method-badge method-post">POST</span>
    <code className="endpoint-url">https://be.datagol.ai/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/data/external</code>
  </div>
  
  <div className="endpoint-body">
    <p>Fetches rows from a table with support for complex filtering, sorting, and pagination.</p>

    <h4>Request Body (JSON)</h4>
    <table>
      <thead>
        <tr>
          <th>Field</th>
          <th>Type</th>
          <th>Required</th>
          <th>Description</th>
          <th>Example</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td><code>requestPageDetails</code></td>
          <td>object</td>
          <td>No</td>
          <td>Pagination settings (pageNumber, pageSize)</td>
          <td><code>{ '{"pageNumber": 1, "pageSize": 500}' }</code></td>
        </tr>
        <tr>
          <td><code>whereClause</code></td>
          <td>string</td>
          <td>No</td>
          <td>SQL-like filter condition. Dates must be in <code>YYYY-MM-DD</code> format.</td>
          <td><code>{"(`first_name` like '%d%' and `years_of_experience` > 4)"}</code></td>
        </tr>
        <tr>
          <td><code>sortOptions</code></td>
          <td>array</td>
          <td>No</td>
          <td>List of sorting rules</td>
          <td><code>{'[{"columnName": "first_name", "direction": "DESC"}]'}</code></td>
        </tr>
      </tbody>
    </table>

    <div className="playground-section">
      <h4>Try it out</h4>
      <ApiPlayground
        method="POST"
        endpoint="/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/data/external"
        defaultBody={{
          requestPageDetails: { pageNumber: 1, pageSize: 500 },
          sortOptions: [{ columnName: "first_name", direction: "DESC" }],
          whereClause: "(`first_name` like '%d%' and `years_of_experience` > 4 and `start_date` between '2004-01-01' and '2009-12-31' and `is_active` = true)"
        }}
        successResponse={{
          pageDetails: { totalRows: 1250, pageNumber: 1 },
          rows: [
            { id: 1, first_name: "Daniel", years_of_experience: 5, start_date: "2005-06-15", is_active: true },
            { id: 2, first_name: "David", years_of_experience: 8, start_date: "2008-01-20", is_active: true },
          ],
        }}
        errorResponse={{
          error: "Forbidden",
          message: "You do not have permission to access this table",
          code: "WS_PERMISSION_DENIED",
        }}
      />
    </div>

  </div>
</div>

### 📊 Column Data Types

When creating columns, use the following `uiDataType` values to define the behavior and validation of your data.

| `uiDataType`       | Description                         | Example Value                     |
| :----------------- | :---------------------------------- | :-------------------------------- |
| `SINGLE_LINE_TEXT` | Short text values.                  | `"Jane Doe"`                      |
| `LONG_TEXT`        | Multi-line text or descriptions.    | `"This is a long description..."` |
| `NUMBER`           | Numeric values (integer/decimal).   | `1250.50`                         |
| `DATE`             | Calendar dates.                     | `"2025-12-31"`                    |
| `CHECKBOX`         | Boolean true/false values.          | `true`                            |
| `FORMULA`          | Calculated values using SQL syntax. | `price * quantity`                |
| `SINGLE_SELECT`    | One value from a predefined list.   | `"Active"`                        |

### Create Column

<div className="endpoint-card">
  <div className="endpoint-header">
    <span className="method-badge method-post">POST</span>
    <code className="endpoint-url">https://be.datagol.ai/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/column</code>
  </div>
  
  <div className="endpoint-body">
    <p>Adds a new column to a table. Supports various data types including Standard and Formula columns.</p>

    <Tabs>
    <TabItem value="standard" label="Standard Column">

    ```json
    {
        "uiDataType": "SINGLE_LINE_TEXT",
        "uiMetadata": {
            "title": "Contact Name"
        },
        "name": "contact_name"
    }
    ```

    </TabItem>
    <TabItem value="formula" label="Formula Column">

    ```json
    {
        "uiDataType": "FORMULA",
        "uiMetadata": {
            "title": "sample demo formula"
        },
        "formula": "length(name)",
        "formulaType": "SQL",
        "name": "sample_demo_formula"
    }
    ```

    </TabItem>
    <TabItem value="ai" label="AI Generated Column">

    ```json
    {
        "uiDataType": "SINGLE_LINE_TEXT",
        "name": "ai_summary",
        "description": "Auto-generated summary",
        "uiMetadata": {
            "title": "AI Summary"
        },
        "required": false,
        "settings": {
            "aiSettings": {
                "enabled": true,
                "prompt": "Summarize the 'description' field in 10 words",
                "model": "gpt-4o-mini",
                "webAccess": false
            }
        }
    }
    ```

    </TabItem>
    </Tabs>

    <div className="important-note">
      <h4>🛠️ How to Enable AI Features</h4>
      <p>To turn a standard column into an AI-powered one, you must include the <code>settings.aiSettings</code> object in your request:</p>
      <ul>
        <li><strong>enabled</strong>: Set to <code>true</code> to activate AI processing.</li>
        <li><strong>prompt</strong>: The "instruction" for the AI (e.g., "Summarize this row").</li>
        <li><strong>model</strong>: Choose between <code>gpt-4o-mini</code> or <code>gpt-4o</code>.</li>
        <li><strong>webAccess</strong>: (Optional) Set to <code>true</code> if the AI needs to browse the internet to find information.</li>
      </ul>
      <p><em>Note: AI columns automatically re-process whenever the source fields they depend on are updated.</em></p>
    </div>

    <div className="playground-section">
      <h4>Try it out</h4>
      <ApiPlayground
        method="POST"
        endpoint="/noCo/api/v2/workspaces/:workspaceId/tables/:tableId/column"
        defaultBody={{
          uiDataType: "FORMULA",
          uiMetadata: { title: "sample demo formula" },
          formula: "length(name)",
          formulaType: "SQL",
          name: "sample_demo_formula"
        }}
        successResponse={{
          id: "col_98765",
          name: "sample_demo_formula",
          status: "CREATED"
        }}
        errorResponse={{
          error: "Bad Request",
          message: "Invalid formula syntax",
          code: "INVALID_FORMULA"
        }}
      />
    </div>

  </div>
</div>
