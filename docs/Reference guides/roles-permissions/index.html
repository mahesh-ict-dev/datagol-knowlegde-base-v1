Roles and permissions

RoleDescription
Account AdminThe Account Admin role provides comprehensive control over the entire data platform, allowing for the highest level of administrative tasks.

The Account Admin has the following permissions:
  • Company Management: Edit company settings.
  • Lakehouse Management
  • Data Source Management: Create, edit, view, and delete data sources.
  • Pipeline Management: Create, edit, view, and delete pipelines.
  • Job Management: View jobs
  • Connector Management: Create, edit, view, and delete connectors.
  • User Management: Create, edit, view, delete users, and assign roles.
Lakehouse AdminThe Lakehouse Admin role focuses on managing lake houses and their associated components, excluding company-wide settings and user management.

The Lakehouse Admin has the following permissions:
  • Lakehouse Management
  • Data Source Management: Create, edit, view, and delete data sources.
  • Pipeline Management: Create, edit, view, and delete pipelines.
  • Job and Alert Management: View jobs and alerts.
Lakehouse MemberLakehouse Member role is designed for users who need read-only access to lake houses and their components.

The Lakehouse Member has the following permissions:
  • Lakehouse Access: View lake houses.
  • Data Source Access: View data sources.
  • Pipeline Access: View pipelines.
  • Job and Alert Management: View jobs and alerts.
Copilots MemberThe Copilot Member role provides read-only access to copilots.

The Copilot Member has the following permission:
  • View copilots
Copilot AdminThe Copilot Admin role is specialized for managing copilots within the data platform.

The Copilot Admin has the following permissions:
  • Create Copilots
  • Edit Copilots
  • View Copilots
  • Delete Copilots
Connectors AdminThe Connectors Admin role is specialized for managing connectors within the data platform.

The Connectors Admin has the following permissions:
  • Connectors Management: Create, edit, view and delete connectors
Connectors MemberThe Connectors Member role provides read-only access to connectors.

The Connectors Member has the following permissions:
  • View Connectors
User AdminThe User Admin role focuses on user administration, allowing for comprehensive user management across the platform.

The User Admin has the following permissions:
  • User Management: Create, edit, view, delete users, and assign roles.
UserThe User has the following permissions:
  • Create edit view Workspace, Workbook and Dashboard.

Users of all types must have access to workspaces to access the workbooks.
BI Dashboard AdminThe BI Admin has the following permissions:
  • View all External Dashboards created within the company.
  • Add or revoke user access to any External Dashboard.
  • Remove pages from existing External Dashboards.

BI Admins do not require explicit sharing to access or manage External Dashboards — visibility is granted automatically across the organization.
