Enums​

PipelineType​

Defines the types of pipelines:

  • CUSTOM - Custom pipeline with user-defined logic
  • STANDARD - Standard data replication pipeline
  • DEDUP - Deduplication pipeline

ScheduleType​

Defines the scheduling types for pipelines:

  • MANUAL - Manual execution only
  • CRON - Cron-based scheduling
  • SCHEDULED - Time-based scheduling
  • DATA_CHANGE - Triggered by data changes

JobStatus​

Defines the job execution status:

  • QUEUED - Job is queued for execution
  • STARTED - Job has started
  • FAILED - Job failed
  • CANCELLED - Job was cancelled
  • COMPLETED - Job completed successfully
  • PENDING - Job is pending
  • RUNNING - Job is currently running
  • INCOMPLETE - Job is incomplete
  • SUCCEEDED - Job succeeded
  • DELETED - Job was deleted
  • UNKNOWN - Job status is unknown
  • PRE_VALIDATION_FAILED - Pre-validation failed
  • POST_VALIDATION_FAILED - Post-validation failed

ProcessType​

Defines the process types:

  • PRE - Pre-processing step
  • POST - Post-processing step

QueryEngine​

Defines the available query engines:

  • SPARK - Apache Spark
  • SNOWFLAKE - Snowflake
  • BIGQUERY - Google BigQuery

SyncMode​

Defines the synchronization modes:

  • FULL - Full synchronization
  • INCREMENTAL - Incremental synchronization

TimeUnitType​

Defines the time unit types:

  • HOUR - Hourly time bucket
  • DAY - Daily time bucket
  • WEEK - Weekly time bucket
  • MONTH - Monthly time bucket
  • YEAR - Yearly time bucket
