# Pipeline History API

The Pipeline History API provides functionality for monitoring pipeline execution history and statistics.

## Get Pipeline Revisions

**POST** `/dataPipeline/api/v2/{dataPipelineId}/getPreviousRevision`

Retrieves revision history for a pipeline.

### Path Parameters

- `dataPipelineId` (number) - The ID of the pipeline

### Request Body

```json
{
  "pageNumber": "number",
  "pageSize": "number"
}
```

### Response

```json
[
  {
    "pipeline": {
      "id": "number",
      "name": "string",
      "type": "string",
      "description": "string",
      "scheduleType": "string",
      "sources": [],
      "destination": {},
      "streams": [],
      "processes": [],
      "parameters": {},
      "workbookMetadata": {},
      "queryEngine": "string",
      "isMvPipeline": "boolean",
      "isLastMilePipeline": "boolean",
      "parentId": "number",
      "clonedParentId": "number",
      "where": {},
      "createdBy": {},
      "createdAt": "date",
      "modifiedAt": "date"
    },
    "modifiedBy": {
      "id": "number",
      "name": "string",
      "email": "string"
    },
    "modifiedAt": "date"
  }
]
```

## Get Job History by Status

**POST** `/dataPipeline/api/v2/job`

Retrieves pipeline jobs based on status and time range.

### Request Body

```json
{
  "status": "QUEUED|STARTED|FAILED|CANCELLED|COMPLETED|PENDING|RUNNING|INCOMPLETE|SUCCEEDED|DELETED|UNKNOWN|PRE_VALIDATION_FAILED|POST_VALIDATION_FAILED",
  "time": {
    "unit": "number",
    "unitType": "HOUR|DAY|WEEK|MONTH|YEAR"
  }
}
```

### Response

Returns a `Page<JobHistoryDTO>`.

## Get Failed Jobs History

**GET** `/dataPipeline/api/v1/getAllFailedJobs/{unit}/{unitType}`

Retrieves all failed jobs within a specified time range.

### Path Parameters

- `unit` (number) - Time unit value
- `unitType` (string) - Time unit type (HOUR|DAY|WEEK|MONTH|YEAR)

### Response

Returns a `Page<JobHistoryDTO>`.

## Get Running Jobs History

**GET** `/dataPipeline/api/v1/getAllRunningJobs`

Retrieves all currently running jobs.

### Response

Returns a `Page<JobHistoryDTO>`.

## Get Scheduled Jobs History

**GET** `/dataPipeline/api/v1/getAllScheduledJobs/{unit}/{unitType}`

Retrieves all scheduled jobs within a specified time range.

### Path Parameters

- `unit` (number) - Time unit value
- `unitType` (string) - Time unit type (HOUR|DAY|WEEK|MONTH|YEAR)

### Response

Returns a `List<PipelineDTO>`.

## Get Job Error Logs

**GET** `/dataPipeline/api/v1/{dataPipelineId}/job/{jobId}/errorLog`

Retrieves error logs for a specific job.

### Path Parameters

- `dataPipelineId` (number) - The ID of the pipeline
- `jobId` (number) - The ID of the job

### Response

```json
{
  "errorLogs": [
    {
      "timestamp": "date",
      "level": "string",
      "message": "string",
      "details": {}
    }
  ]
}
```

## Get Pipeline Statistics

**GET** `/dataPipeline/api/v2/statistics`

Retrieves pipeline execution statistics.

### Query Parameters

- `since` (date, optional) - Start date for statistics (ISO format)
- `until` (date, optional) - End date for statistics (ISO format)

### Response

```json
{
  "totalPipelines": "number",
  "activePipelines": "number",
  "failedJobs": "number",
  "successfulJobs": "number",
  "runningJobs": "number",
  "averageExecutionTime": "number",
  "successRate": "number"
}
```

## Get Pipeline Performance Metrics

**GET** `/dataPipeline/api/v2/{pipelineId}/metrics`

Retrieves performance metrics for a specific pipeline.

### Path Parameters

- `pipelineId` (number) - The ID of the pipeline

### Query Parameters

- `timeRange` (string) - Time range for metrics (LAST_HOUR|LAST_DAY|LAST_WEEK|LAST_MONTH)

### Response

```json
{
  "pipelineId": "number",
  "executionCount": "number",
  "successCount": "number",
  "failureCount": "number",
  "averageExecutionTime": "number",
  "totalDataProcessed": "number",
  "lastExecutionTime": "date",
  "nextScheduledExecution": "date"
}
```
