# Pipeline Jobs API

The Pipeline Jobs API provides functionality for executing, monitoring, and managing pipeline jobs.

## Run Pipeline

**POST** `/dataPipeline/api/v1/{pipelineId}/run`

Executes a pipeline immediately.

### Path Parameters

- `pipelineId` (number) - The ID of the pipeline to run

### Request Body

```json
{
  "parameter1": "value1",
  "parameter2": "value2"
}
```

### Response

Returns a `JobDTO` object.

## Get Job by ID

**GET** `/dataPipeline/api/v1/{pipelineId}/job/{jobId}`

Retrieves a specific job for a pipeline.

### Path Parameters

- `pipelineId` (number) - The ID of the pipeline
- `jobId` (number) - The ID of the job

### Response

Returns a `JobDTO` object.

## Cancel Job

**GET** `/dataPipeline/api/v1/{dataPipelineId}/job/{jobId}/cancelSync`

Cancels a running job.

### Path Parameters

- `dataPipelineId` (number) - The ID of the pipeline
- `jobId` (number) - The ID of the job to cancel

### Response

`204 No Content`

## Get Job Error Log

**GET** `/dataPipeline/api/v1/{dataPipelineId}/job/{jobId}/errorLog`

Retrieves error logs for a specific job.

### Path Parameters

```json
      "timestamp": "date",

      "message": "string",
      "details": {}
    }
  ]
}
```

## Migrate All Pipelines

**POST** `/dataPipeline/api/v1/migrateAllPipelines`

Migrates all pipelines to the new system (Deprecated).

### Response

## Platform Pipeline Status Email

**GET** `/dataPipeline/api/v1/platformPipeline/status/email/{token}`

Sends platform pipeline status via email.

### Path Parameters

- `token` (string) - Secret token for authentication
