# Materialized Views API

The Materialized Views API provides operations for managing materialized views within data sources.

## View CRUD Operations

### Get All Materialized Views

**GET** `/dataSources/api/v1/internal/materializedViews`

Retrieves all materialized views.

### Required Roles
- `ROLE_VIEW_LAKEHOUSE`
- `ROLE_VIEW_DATASOURCE`

### Response

Returns a `List<MaterializedViewDTO>`.

### Create Materialized View

**POST** `/dataSources/api/v1/internal/materializedViews`

Creates a new materialized view.

### Required Roles
- `ROLE_VIEW_LAKEHOUSE`
- `ROLE_VIEW_DATASOURCE`

### Request Body

```json
{
  "name": "string",
  "description": "string",
  "query": "string",
  "dataSourceId": "string",
  "refreshSchedule": "string",
  "columns": [
    {
      "name": "string",
      "type": "string"
    }
  ]
}
```

### Response

Returns a `MaterializedViewDTO` object.

### Get View by ID

**GET** `/dataSources/api/v1/internal/materializedViews/{viewId}`

Retrieves a specific materialized view by ID.

### Required Roles
- `ROLE_VIEW_LAKEHOUSE`
- `ROLE_VIEW_DATASOURCE`

### Path Parameters

- `viewId` (string) - The ID of the materialized view

### Response

Returns a `MaterializedViewDTO` object.

### Update View

**PUT** `/dataSources/api/v1/internal/materializedViews/{viewId}`

Updates an existing materialized view.

### Required Roles
- `ROLE_VIEW_LAKEHOUSE`
- `ROLE_VIEW_DATASOURCE`

### Path Parameters

- `viewId` (string) - The ID of the materialized view to update

### Request Body

Same as Create Materialized View

### Response

Returns a `MaterializedViewDTO` object.

### Delete View

**DELETE** `/dataSources/api/v1/internal/materializedViews/{viewId}`

Deletes a materialized view.

### Required Roles
- `ROLE_VIEW_LAKEHOUSE`
- `ROLE_VIEW_DATASOURCE`

### Path Parameters

- `viewId` (string) - The ID of the materialized view to delete

### Response

`204 No Content`
