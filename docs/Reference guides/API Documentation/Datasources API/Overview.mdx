# Datasources API Documentation

## Overview

The Datasources API provides comprehensive functionality for managing data sources, tables, columns, queries, annotations, and related metadata. The API is organized into multiple controllers covering different aspects of data source management.

## Base URLs

- **DataSources**: `/dataSources/api/v1`
- **Queries**: `/dataSources/api/v1/queries`
- **Annotations**: `/dataSources/api/v1/annotation`
- **Glossaries**: `/dataSources/api/v1/glossaries`

## Authentication

All Datasources APIs require JWT authentication via the `s_jwt` security requirement.
