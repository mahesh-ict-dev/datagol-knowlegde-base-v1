# Internal Operations API

The Internal Operations API provides operations for configuration management, migration operations, and internal data source access.

## Configuration

### Get DataSource Configurations

**GET** `/dataSources/api/v1/config/dataSources`

Retrieves datasource configurations.

### Required Roles
- `ROLE_VIEW_LAKEHOUSE`
- `ROLE_VIEW_DATASOURCE`

### Response

Returns a `List<DataSourceConfigDTO>`.

## Migration Operations

### Migrate Existing REST DataSources

**POST** `/dataSources/api/v1/internal/migrateExistingRestDataSource`

Migrates existing REST datasources to the new format.

### Required Roles
- `ROLE_CREATE_LAKEHOUSE`
- `ROLE_CREATE_DATASOURCE`

### Request Body

```json
{
  "sourceDataSourceId": "string",
  "targetDataSourceConfig": {
    "name": "string",
    "description": "string",
    "type": "REST",
    "connectionConfig": {
      "baseUrl": "string",
      "headers": {
        "key": "value"
      }
    }
  }
}
```

### Response

Returns a `MigrationResponseDTO` object.

### Migrate Existing Folder DataSources

**POST** `/dataSources/api/v1/internal/migrateExistingFolderDataSource`

Migrates existing folder datasources to the new format.

### Required Roles
- `ROLE_CREATE_LAKEHOUSE`
- `ROLE_CREATE_DATASOURCE`

### Request Body

```json
{
  "sourceDataSourceId": "string",
  "targetDataSourceConfig": {
    "name": "string",
    "description": "string",
    "type": "FOLDER",
    "storageConfig": {
      "folderPath": "string",
      "filePattern": "string"
    }
  }
}
```

### Response

Returns a `MigrationResponseDTO` object.

## Internal DataSource Access

### Get Tables by DataSource (Internal)

**GET** `/dataSources/api/v1/dataSources/internal/{token}/{dataSourceId}/tables`

Retrieves tables for a datasource using internal token access.

### Required Authentication
- Internal token required

### Path Parameters

- `token` (string) - Internal access token
- `dataSourceId` (string) - The ID of the datasource

### Response

Returns a `List<TableDTO>`.
