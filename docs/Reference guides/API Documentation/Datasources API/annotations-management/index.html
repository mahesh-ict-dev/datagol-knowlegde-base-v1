Annotations Management API

The Annotations Management API provides operations for managing annotations, element annotations, and classifications.

Annotations​

Get All Annotations​

GET /dataSources/api/v1/annotation

Retrieves all annotations.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Response​

Returns a List<AnnotationDTO>.

Create Annotation​

POST /dataSources/api/v1/annotation

Creates a new annotation.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Request Body​

{
  "name": "string",
  "description": "string",
  "type": "string",
  "value": "string"
}

Response​

Returns an AnnotationDTO object.

Element Annotations​

Get All Element Annotations​

GET /dataSources/api/v1/elementAnnotations

Retrieves all element annotations.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Response​

Returns a List<ElementAnnotationDTO>.

Create Element Annotations​

POST /dataSources/api/v1/elementAnnotations

Creates new element annotations.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Request Body​

{
  "elementId": "string",
  "elementType": "string",
  "annotations": [
    {
      "name": "string",
      "value": "string"
    }
  ]
}

Response​

Returns a List<ElementAnnotationDTO>.

Get Annotations by Element ID​

GET /dataSources/api/v1/elementAnnotations/{elementId}

Retrieves annotations for a specific element.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • elementId (string) - The ID of the element

Response​

Returns a List<ElementAnnotationDTO>.

Get Annotations by Table ID​

GET /dataSources/api/v1/elementAnnotations/table/{tableId}

Retrieves annotations for a specific table.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • tableId (string) - The ID of the table

Response​

Returns a List<ElementAnnotationDTO>.

Update Element Annotations​

PUT /dataSources/api/v1/elementAnnotations/{elementId}

Updates annotations for a specific element.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • elementId (string) - The ID of the element

Request Body​

{
  "annotations": [
    {
      "name": "string",
      "value": "string"
    }
  ]
}

Response​

Returns a List<ElementAnnotationDTO>.

Delete Annotation​

DELETE /dataSources/api/v1/elementAnnotations/{elementAnnotationId}

Deletes a specific annotation.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • elementAnnotationId (string) - The ID of the element annotation

Response​

204 No Content

Classifications​

Get All Classifications​

GET /dataSources/api/v1/classifications

Retrieves all classifications.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Response​

Returns a List<ClassificationDTO>.

Create Classification​

POST /dataSources/api/v1/classifications

Creates a new classification.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Request Body​

{
  "name": "string",
  "description": "string",
  "type": "string",
  "value": "string"
}

Response​

Returns a ClassificationDTO object.

Get Classification by ID​

GET /dataSources/api/v1/classifications/{classificationId}

Retrieves a specific classification by ID.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • classificationId (string) - The ID of the classification

Response​

Returns a ClassificationDTO object.

Update Classification​

PUT /dataSources/api/v1/classifications/{classificationId}

Updates an existing classification.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • classificationId (string) - The ID of the classification to update

Request Body​

Same as Create Classification

Response​

Returns a ClassificationDTO object.

Delete Classification​

DELETE /dataSources/api/v1/classifications/{classificationId}

Deletes a classification.

Required Roles​

  • ROLE_VIEW_LAKEHOUSE
  • ROLE_VIEW_DATASOURCE

Path Parameters​

  • classificationId (string) - The ID of the classification to delete

Response​

204 No Content
