DAG Run Management API

The DAG Run Management API provides endpoints for managing DAG execution instances, monitoring run status, and controlling workflow execution.

Get DAG Runs​

Endpoint: GET /orchestration/api/v1/dags/{dagId}/runs

Retrieves all runs for a specific DAG.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Query Parameters​

ParameterTypeRequiredDescription
includeJobsBooleanNoInclude job details in response (default: false)
statusStringNoFilter by run status
limitIntegerNoMaximum number of runs to return (default: 50)
offsetIntegerNoNumber of runs to skip (default: 0)

Response​

{
  "data": [
    {
      "id": 301,
      "dagId": 1,
      "status": "COMPLETED",
      "startTime": "2024-01-15T10:00:00Z",
      "endTime": "2024-01-15T10:15:00Z",
      "type": "MANUAL",
      "createdBy": {
        "id": 456,
        "email": "user@example.com"
      },
      "parameters": {
        "sourceTable": "raw_data",
        "targetTable": "processed_data"
      },
      "jobMappings": [
        {
          "id": 401,
          "dagRunId": 301,
          "dagNodeId": 101,
          "executionOrder": 1,
          "jobId": 501,
          "parameters": {}
        }
      ]
    }
  ],
  "pagination": {
    "total": 25,
    "limit": 50,
    "offset": 0
  }
}

Example Request​

curl -X GET "https://api.saasxl.com/orchestration/api/v1/dags/1/runs?includeJobs=true&limit=10" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Create DAG Run​

Endpoint: POST /orchestration/api/v1/dags/{dagId}/runs

Initiates a new DAG run.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Request Body (optional)​

{
  "parameters": {
    "sourceTable": "raw_data_v2",
    "targetTable": "processed_data_v2",
    "customParam": "value"
  }
}

Response​

{
  "id": 302,
  "dagId": 1,
  "status": "PENDING",
  "startTime": "2024-01-15T11:00:00Z",
  "type": "MANUAL",
  "createdBy": {
    "id": 456,
    "email": "user@example.com"
  },
  "parameters": {
    "sourceTable": "raw_data_v2",
    "targetTable": "processed_data_v2",
    "customParam": "value"
  },
  "jobMappings": [
    {
      "id": 401,
      "dagRunId": 302,
      "dagNodeId": 101,
      "executionOrder": 1,
      "parameters": {}
    }
  ]
}

Example Request​

curl -X POST "https://api.saasxl.com/orchestration/api/v1/dags/1/runs" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "parameters": {
      "sourceTable": "raw_data_v2",
      "targetTable": "processed_data_v2",
      "customParam": "value"
    }
  }'

ParameterTypeRequiredDescription

runIdLongYesThe run ID

Request Body (optional)​

Get DAG Run Logs​

Endpoint: GET /orchestration/api/v1/dags/{dagId}/runs/{runId}/logs

Retrieves execution logs for a DAG run.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID
runIdLongYesThe run ID

Query Parameters​

ParameterTypeRequiredDescription
nodeIdLongNoFilter logs by specific node
levelStringNoFilter by log level (INFO, WARN, ERROR)
limitIntegerNoMaximum number of log entries (default: 100)

Response​

{
  "data": [
    {
      "timestamp": "2024-01-15T10:00:00Z",
      "level": "INFO",
      "nodeId": 101,
      "nodeName": "Data Extraction",
      "message": "Starting data extraction from source",
      "details": {
        "sourceTable": "raw_data",
        "recordCount": 1000
      }
    },
    {
      "timestamp": "2024-01-15T10:05:00Z",
      "level": "INFO",
      "nodeId": 101,
      "nodeName": "Data Extraction",
      "message": "Data extraction completed successfully",
      "details": {
        "extractedRecords": 1000,
        "duration": 300
      }
    }
  ]
}

Example Request​

curl -X GET "https://api.saasxl.com/orchestration/api/v1/dags/1/runs/301/logs?level=ERROR" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Run Status Monitoring​

Run Status Values​

StatusDescription
PENDINGRun is queued for execution
RUNNINGRun is currently executing
COMPLETEDRun completed successfully
FAILEDRun failed during execution
CANCELLEDRun was cancelled by user
PAUSEDRun is paused (manual intervention required)

Status Transition Rules​

  • PENDING → RUNNING (automatic)
  • RUNNING → COMPLETED (automatic, all nodes succeed)
  • RUNNING → FAILED (automatic, any node fails)
  • RUNNING → CANCELLED (manual)
  • RUNNING → PAUSED (manual or system)
  • PAUSED → RUNNING (manual resume)
  • FAILED → PENDING (retry)

Run Parameters​

Parameter Inheritance​

DAG runs inherit parameters from the DAG's default parameters and can be overridden:

{
  "parameters": {
    "sourceTable": "raw_data_v2",        // Override default
    "targetTable": "processed_data_v2",  // Override default
    "customParam": "value",              // New parameter
    "batchSize": 1000                    // New parameter
  }
}

Parameter Validation​

  • Parameters must be valid JSON
  • Maximum parameter size: 50KB
  • Reserved parameter names: dagId, runId, status, startTime, endTime

Run Execution Flow​

Execution Order​

  1. Validation: Validate DAG structure and parameters
  2. Snapshot: Create DAG snapshot for version control
  3. Job Mapping: Create job mappings for each node
  4. Execution: Execute nodes in topological order
  5. Monitoring: Track execution status and logs
  6. Completion: Update final status and metrics

Parallel Execution​

Nodes without dependencies can execute in parallel:

{
  "jobMappings": [
    {
      "dagNodeId": 101,
      "executionOrder": 1,
      "status": "RUNNING"
    },
    {
      "dagNodeId": 102,
      "executionOrder": 1,  // Same order = parallel execution
      "status": "RUNNING"
    },
    {
      "dagNodeId": 103,
      "executionOrder": 2,  // Higher order = sequential execution
      "status": "PENDING"
    }
  ]
}

Error Scenarios​

Common Error Responses​

Status CodeError TypeDescription
400Bad RequestInvalid parameters or DAG configuration
404Not FoundDAG or run not found
409ConflictDAG already running or invalid state transition
422Unprocessable EntityDAG validation failed

Example Error Response​

{
  "error": {
    "code": "DAG_ALREADY_RUNNING",
    "message": "A new run cannot be created because this DAG is already running.",
    "timestamp": "2024-01-15T10:30:00Z"
  }
}
