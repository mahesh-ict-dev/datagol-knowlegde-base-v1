DAG Node Management API

The DAG Node Management API provides endpoints for managing nodes (pipelines) within a DAG workflow.

Create Node​

Endpoint: POST /orchestration/api/v1/dags/{dagId}/nodes

Adds a new node (pipeline) to the DAG.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Request Body​

{
  "pipelineId": 789,
  "metadata": {
    "description": "Data extraction pipeline",
    "priority": "high"
  }
}

Response​

{
  "id": 101,
  "dagId": 1,
  "pipelineId": 789,
  "metadata": {
    "description": "Data extraction pipeline",
    "priority": "high"
  },
  "createdAt": "2024-01-15T10:35:00Z"
}

Example Request​

curl -X POST "https://api.saasxl.com/orchestration/api/v1/dags/1/nodes" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "pipelineId": 789,
    "metadata": {
      "description": "Data extraction pipeline",
      "priority": "high"
    }
  }'

Update Node​

Endpoint: PUT /orchestration/api/v1/dags/{dagId}/nodes/{nodeId}

Updates a specific node in the DAG.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID
nodeIdLongYesThe node ID

Request Body​

{
  "pipelineId": 790,
  "metadata": {
    "description": "Updated data extraction pipeline",
    "priority": "medium"
  }
}

Example Request​

curl -X PUT "https://api.saasxl.com/orchestration/api/v1/dags/1/nodes/101" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "pipelineId": 790,
    "metadata": {
      "description": "Updated data extraction pipeline",
      "priority": "medium"
    }
  }'

Update Multiple Nodes​

Endpoint: PUT /orchestration/api/v1/dags/{dagId}/nodes

Updates multiple nodes in the DAG at once.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Request Body​

{
  "nodes": [
    {
      "id": 101,
      "pipelineId": 789,
      "metadata": {
        "description": "Updated extraction pipeline"
      }
    },
    {
      "id": 102,
      "pipelineId": 790,
      "metadata": {
        "description": "Updated transformation pipeline"
      }
    }
  ]
}

Example Request​

curl -X PUT "https://api.saasxl.com/orchestration/api/v1/dags/1/nodes" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "nodes": [
      {
        "id": 101,
        "pipelineId": 789,
        "metadata": {
          "description": "Updated extraction pipeline"
        }
      },
      {
        "id": 102,
        "pipelineId": 790,
        "metadata": {
          "description": "Updated transformation pipeline"
        }
      }
    ]
  }'

Delete Node​

Endpoint: DELETE /orchestration/api/v1/dags/{dagId}/nodes/{nodeId}

Removes a node from the DAG.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID
nodeIdLongYesThe node ID

Example Request​

curl -X DELETE "https://api.saasxl.com/orchestration/api/v1/dags/1/nodes/101" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Node Metadata Guidelines​

Common Metadata Fields​

FieldTypeDescriptionExample
descriptionStringHuman-readable description of the node"Data extraction from source database"
priorityStringExecution priority"high", "medium", "low"
timeoutNumberExecution timeout in seconds3600
retryCountNumberNumber of retry attempts3
retryDelayNumberDelay between retries in seconds300
tagsArrayTags for categorization["extract", "critical"]
environmentStringTarget environment"production", "staging"

Example Node Creation with Full Metadata​

curl -X POST "https://api.saasxl.com/orchestration/api/v1/dags/1/nodes" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "pipelineId": 789,
    "metadata": {
      "description": "Extract user data from production database",
      "priority": "high",
      "timeout": 3600,
      "retryCount": 3,
      "retryDelay": 300,
      "tags": ["extract", "users", "critical"],
      "environment": "production",
      "dependencies": ["database_connection"],
      "expectedDuration": 1800
    }
  }'

Node Validation Rules​

Pipeline ID Validation​

  • Pipeline ID must exist in the system
  • Pipeline must be accessible to the current user
  • Pipeline must be compatible with the DAG's company context

Metadata Validation​

  • Metadata must be a valid JSON object
  • Maximum metadata size: 10KB
  • Reserved keys: id, dagId, pipelineId, createdAt, updatedAt

Node Limits​

  • Maximum nodes per DAG: 100
  • Maximum concurrent nodes: 20 (configurable)
  • Node names must be unique within a DAG (if specified)

Error Scenarios​

Common Error Responses​

Status CodeError TypeDescription
400Bad RequestInvalid pipeline ID or metadata
404Not FoundDAG or pipeline not found
409ConflictNode limit exceeded or duplicate node
422Unprocessable EntityInvalid node configuration

Example Error Response​

{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Pipeline ID 999 does not exist or is not accessible",
    "timestamp": "2024-01-15T10:30:00Z"
  }
}
