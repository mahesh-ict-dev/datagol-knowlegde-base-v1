DAG Management API

The DAG Management API provides endpoints for creating, reading, updating, and deleting Directed Acyclic Graph (DAG) workflows.

Get All DAGs​

Endpoint: GET /orchestration/api/v1/dags

Retrieves all DAGs accessible to the user.

Query Parameters​

ParameterTypeRequiredDescription
pipelineIdList<Long>NoFilter DAGs by pipeline IDs

Response​

{
  "data": [
    {
      "id": 1,
      "name": "Data Processing Workflow",
      "companyId": 123,
      "createdAt": "2024-01-15T10:30:00Z",
      "createdBy": {
        "id": 456,
        "email": "user@example.com"
      },
      "nodes": [],
      "edges": [],
      "scheduleType": "MANUAL"
    }
  ]
}

Example Request​

curl -X GET "https://api.saasxl.com/orchestration/api/v1/dags" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Create DAG​

Endpoint: POST /orchestration/api/v1/dags

Creates a new DAG workflow.

Request Body​

{
  "name": "Data Processing Workflow",
  "scheduleType": "SCHEDULED",
  "schedule": {
    "basicSchedule": {
      "timeUnit": "HOUR",
      "units": "24"
    }
  },
  "defaultParameters": {
    "sourceTable": "raw_data",
    "targetTable": "processed_data"
  },
  "metadata": {
    "description": "Daily data processing workflow"
  }
}

Response​

{
  "id": 1,
  "name": "Data Processing Workflow",
  "companyId": 123,
  "createdAt": "2024-01-15T10:30:00Z",
  "createdBy": {
    "id": 456,
    "email": "user@example.com"
  },
  "scheduleType": "SCHEDULED",
  "schedule": {
    "basicSchedule": {
      "timeUnit": "HOUR",
      "units": "24"
    }
  }
}

Example Request​

curl -X POST "https://api.saasxl.com/orchestration/api/v1/dags" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Data Processing Workflow",
    "scheduleType": "SCHEDULED",
    "schedule": {
      "basicSchedule": {
        "timeUnit": "HOUR",
        "units": "24"
      }
    }
  }'

Get DAG by ID​

Endpoint: GET /orchestration/api/v1/dags/{dagId}

Retrieves a specific DAG by its ID.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Response​

{
  "id": 1,
  "name": "Data Processing Workflow",
  "companyId": 123,
  "createdAt": "2024-01-15T10:30:00Z",
  "createdBy": {
    "id": 456,
    "email": "user@example.com"
  },
  "nodes": [
    {
      "id": 101,
      "dagId": 1,
      "pipelineId": 789,
      "metadata": {
        "description": "Data extraction pipeline"
      }
    }
  ],
  "edges": [
    {
      "id": 201,
      "dagId": 1,
      "fromNodeId": 101,
      "toNodeId": 102,
      "metadata": {
        "condition": "success"
      }
    }
  ],
  "latestRun": {
    "id": 301,
    "status": "COMPLETED",
    "startTime": "2024-01-15T10:00:00Z",
    "endTime": "2024-01-15T10:15:00Z"
  },
  "scheduleType": "SCHEDULED"
}

Example Request​

curl -X GET "https://api.saasxl.com/orchestration/api/v1/dags/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Update DAG​

Endpoint: PUT /orchestration/api/v1/dags/{dagId}

Updates an existing DAG.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Request Body​

{
  "name": "Updated Data Processing Workflow",
  "scheduleType": "CRON",
  "schedule": {
    "cronExpression": "0 0 2 * * ?"
  },
  "defaultParameters": {
    "sourceTable": "raw_data_v2",
    "targetTable": "processed_data_v2"
  }
}

Example Request​

curl -X PUT "https://api.saasxl.com/orchestration/api/v1/dags/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Data Processing Workflow",
    "scheduleType": "CRON",
    "schedule": {
      "cronExpression": "0 0 2 * * ?"
    }
  }'

Delete DAG​

Endpoint: DELETE /orchestration/api/v1/dags/{dagId}

Deletes a DAG and all its associated data.

Path Parameters​

ParameterTypeRequiredDescription
dagIdLongYesThe DAG ID

Example Request​

curl -X DELETE "https://api.saasxl.com/orchestration/api/v1/dags/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Scheduling Configuration​

Cron Expressions​

For ScheduleType.CRON, use standard cron expressions:

ExpressionDescription
0 0 2 * * ?Daily at 2 AM
0 0 */6 * * ?Every 6 hours
0 30 9 * * MON-FRIWeekdays at 9:30 AM
0 0 0 1 1 ?Yearly on January 1st

Basic Scheduling​

For ScheduleType.SCHEDULED, use time units:

Time UnitDescriptionExample
SECONDExecute every N seconds{"timeUnit": "SECOND", "units": "30"}
MINUTEExecute every N minutes{"timeUnit": "MINUTE", "units": "15"}
HOURExecute every N hours{"timeUnit": "HOUR", "units": "24"}
DAYExecute every N days{"timeUnit": "DAY", "units": "7"}
WEEKExecute every N weeks{"timeUnit": "WEEK", "units": "2"}
MONTHExecute every N months{"timeUnit": "MONTH", "units": "1"}
YEARExecute every N years{"timeUnit": "YEAR", "units": "1"}
