Examples

This section provides practical examples of how to use the Alerts API.

Creating an Alert​

Basic Alert Creation​

curl -X POST "https://api.example.com/alerts/api/v1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "High CPU Usage Alert",
    "description": "Alert when CPU usage exceeds 80%",
    "recipients": ["admin@example.com"],
    "scheduleType": "CRON",
    "cronExpression": "0 */5 * * * *",
    "sourceType": "METRICS",
    "sourceId": "cpu_usage",
    "config": {
      "threshold": 80,
      "operator": "GREATER_THAN"
    }
  }'

Alert with Element Links​

curl -X POST "https://api.example.com/alerts/api/v1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Database Connection Alert",
    "description": "Alert when database connections exceed threshold",
    "recipients": ["dba@example.com", "admin@example.com"],
    "scheduleType": "CRON",
    "cronExpression": "0 */2 * * * *",
    "sourceType": "DATABASE",
    "sourceId": "postgres_main",
    "config": {
      "threshold": 100,
      "operator": "GREATER_THAN",
      "query": "SELECT COUNT(*) FROM pg_stat_activity"
    },
    "elementLinks": [
      {
        "elementId": "db-connection-dashboard",
        "elementType": "DASHBOARD"
      },
      {
        "elementId": "db-metrics-workbook",
        "elementType": "WORKBOOK"
      }
    ]
  }'

Getting Alert History​

Basic History Retrieval​

curl -X GET "https://api.example.com/alerts/history/api/v1/alert/alert-123" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Paginated History with Sorting​

curl -X GET "https://api.example.com/alerts/history/api/v1/alert/alert-123/paginated?page=0&size=10&sort=executedAt,desc" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Company-wide Alert Statistics​

curl -X GET "https://api.example.com/alerts/history/api/v1/statistics?since=2024-01-01T00:00:00.000Z" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

Mark Notifications as Seen​

curl -X POST "https://api.example.com/alerts/notification-history/mark-seen-by-elements" \

  -H "Authorization: Bearer YOUR_JWT_TOKEN"

JavaScript Examples​

Creating an Alert with JavaScript​

async function createAlert(alertData) {
  const response = await fetch('/alerts/api/v1', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(alertData)
  });

  if (!response.ok) {
    throw new Error(`Failed to create alert: ${response.statusText}`);
  }

  return await response.json();
}

// Usage
const alertData = {
  name: 'Sales Threshold Alert',
  description: 'Alert when daily sales exceed $10,000',
  recipients: ['sales@example.com'],
  scheduleType: 'CRON',
  cronExpression: '0 0 18 * * *', // Daily at 6 PM
  sourceType: 'SALES_DATA',
  sourceId: 'daily_sales',
  config: {
    threshold: 10000,
    operator: 'GREATER_THAN'
  }
};

createAlert(alertData)
  .then(alert => console.log('Alert created:', alert))
  .catch(error => console.error('Error:', error));

Getting Alert History with JavaScript​

async function getAlertHistory(alertId, page = 0, size = 20) {
  const response = await fetch(
    `/alerts/history/api/v1/alert/${alertId}/paginated?page=${page}&size=${size}&sort=executedAt,desc`,
    {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    }
  );

  if (!response.ok) {
    throw new Error(`Failed to get alert history: ${response.statusText}`);
  }

  return await response.json();
}

// Usage
getAlertHistory('alert-123', 0, 10)
  .then(history => console.log('Alert history:', history))
  .catch(error => console.error('Error:', error));

Python Examples​

Creating an Alert with Python​

import requests
import json

def create_alert(alert_data, token):
    headers = {
        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json'
    }
    
    response = requests.post(
        '/alerts/api/v1',
        json=alert_data,
        headers=headers
    )
    
    response.raise_for_status()
    return response.json()

# Usage
alert_data = {
    'name': 'Error Rate Alert',
    'description': 'Alert when error rate exceeds 5%',
    'recipients': ['devops@example.com'],
    'scheduleType': 'CRON',
    'cronExpression': '0 */10 * * * *',  # Every 10 minutes
    'sourceType': 'ERROR_METRICS',
    'sourceId': 'error_rate',
    'config': {
        'threshold': 5.0,
        'operator': 'GREATER_THAN'
    }
}

try:
    alert = create_alert(alert_data, 'your-jwt-token')
    print(f"Alert created: {alert['id']}")
except requests.exceptions.RequestException as e:
    print(f"Error creating alert: {e}")

Managing Notifications with Python​

import requests
from datetime import datetime, timedelta

def mark_notifications_seen(element_filters, token):
    headers = {
        'Authorization': f'Bearer {token}',
        'Content-Type': 'application/json'
    }
    
    response = requests.post(
        '/alerts/notification-history/mark-seen-by-elements',
        json=element_filters,
        headers=headers
    )
    
    response.raise_for_status()
    return response.json()

def get_notification_history_by_date_range(alert_id, start_date, end_date, token):
    headers = {
        'Authorization': f'Bearer {token}'
    }
    
    params = {
        'startDate': start_date.isoformat(),
        'endDate': end_date.isoformat(),
        'page': 0,
        'size': 50
    }
    
    response = requests.get(
        f'/alerts/notification-history/alert/{alert_id}/date-range',
        params=params,
        headers=headers
    )
    
    response.raise_for_status()
    return response.json()

# Usage
element_filters = [
    {
        'elementId': 'dashboard-123',
        'elementType': 'DASHBOARD'
    }
]

try:
    result = mark_notifications_seen(element_filters, 'your-jwt-token')
    print(f"Marked {result['updatedCount']} notifications as seen")
except requests.exceptions.RequestException as e:
    print(f"Error marking notifications: {e}")

# Get notifications for the last 7 days
end_date = datetime.now()
start_date = end_date - timedelta(days=7)

try:
    history = get_notification_history_by_date_range(
        'alert-123', 
        start_date, 
        end_date, 
        'your-jwt-token'
    )
    print(f"Found {len(history)} notifications")
except requests.exceptions.RequestException as e:
    print(f"Error getting notification history: {e}")

React/TypeScript Examples​

Alert Management Hook​

import { useState, useEffect } from 'react';

interface Alert {
  id: string;
  name: string;
  description: string;
  status: string;
  recipients: string[];
  scheduleType: string;
  config: Record<string, any>;
}

interface UseAlertsReturn {
  alerts: Alert[];
  loading: boolean;
  error: string | null;
  createAlert: (alertData: Partial<Alert>) => Promise<void>;
  updateAlert: (id: string, alertData: Partial<Alert>) => Promise<void>;
  deleteAlert: (id: string) => Promise<void>;
  activateAlert: (id: string) => Promise<void>;
  deactivateAlert: (id: string) => Promise<void>;
}

export function useAlerts(token: string): UseAlertsReturn {
  const [alerts, setAlerts] = useState<Alert[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const fetchAlerts = async () => {
    try {
      const response = await fetch('/alerts/api/v1', {
        headers: {
          'Authorization': `Bearer ${token}`
        }
      });

      if (!response.ok) {
        throw new Error('Failed to fetch alerts');
      }

      const data = await response.json();
      setAlerts(data);
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Unknown error');
    } finally {
      setLoading(false);
    }
  };

  const createAlert = async (alertData: Partial<Alert>) => {
    try {
      const response = await fetch('/alerts/api/v1', {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(alertData)
      });

      if (!response.ok) {
        throw new Error('Failed to create alert');
      }

      await fetchAlerts(); // Refresh the list
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Unknown error');
    }
  };

  const updateAlert = async (id: string, alertData: Partial<Alert>) => {
    try {
      const response = await fetch(`/alerts/api/v1/${id}`, {
        method: 'PUT',
        headers: {
          'Authorization': `Bearer ${token}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(alertData)
      });

      if (!response.ok) {
        throw new Error('Failed to update alert');
      }

      await fetchAlerts(); // Refresh the list
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Unknown error');
    }
  };

  const deleteAlert = async (id: string) => {
    try {
      const response = await fetch(`/alerts/api/v1/${id}`, {
        method: 'DELETE',
        headers: {
          'Authorization': `Bearer ${token}`
        }
      });

      if (!response.ok) {
        throw new Error('Failed to delete alert');
      }

      await fetchAlerts(); // Refresh the list
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Unknown error');
    }
  };

  const activateAlert = async (id: string) => {
    try {
      const response = await fetch(`/alerts/api/v1/${id}/activate`, {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token}`
        }
      });

      if (!response.ok) {
        throw new Error('Failed to activate alert');
      }

      await fetchAlerts(); // Refresh the list
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Unknown error');
    }
  };

  const deactivateAlert = async (id: string) => {
    try {
      const response = await fetch(`/alerts/api/v1/${id}/deactivate`, {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${token}`
        }
      });

      if (!response.ok) {
        throw new Error('Failed to deactivate alert');
      }

      await fetchAlerts(); // Refresh the list
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Unknown error');
    }
  };

  useEffect(() => {
    fetchAlerts();
  }, [token]);

  return {
    alerts,
    loading,
    error,
    createAlert,
    updateAlert,
    deleteAlert,
    activateAlert,
    deactivateAlert
  };
}

React Component Example​

import React, { useState } from 'react';
import { useAlerts } from './useAlerts';

interface AlertFormProps {
  token: string;
}

export function AlertForm({ token }: AlertFormProps) {
  const { createAlert, loading, error } = useAlerts(token);
  const [formData, setFormData] = useState({
    name: '',
    description: '',
    recipients: '',
    scheduleType: 'CRON',
    cronExpression: '0 */5 * * * *',
    threshold: '',
    operator: 'GREATER_THAN'
  });

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    
    const alertData = {
      name: formData.name,
      description: formData.description,
      recipients: formData.recipients.split(',').map(email => email.trim()),
      scheduleType: formData.scheduleType,
      cronExpression: formData.cronExpression,
      sourceType: 'METRICS',
      sourceId: 'custom_metric',
      config: {
        threshold: parseFloat(formData.threshold),
        operator: formData.operator
      }
    };

    await createAlert(alertData);
    
    // Reset form
    setFormData({
      name: '',
      description: '',
      recipients: '',
      scheduleType: 'CRON',
      cronExpression: '0 */5 * * * *',
      threshold: '',
      operator: 'GREATER_THAN'
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      <h2>Create New Alert</h2>
      
      {error && <div className="error">{error}</div>}
      
      <div>
        <label htmlFor="name">Alert Name:</label>
        <input
          type="text"
          id="name"
          value={formData.name}
          onChange={(e) => setFormData({...formData, name: e.target.value})}
          required
        />
      </div>
      
      <div>
        <label htmlFor="description">Description:</label>
        <textarea
          id="description"
          value={formData.description}
          onChange={(e) => setFormData({...formData, description: e.target.value})}
          required
        />
      </div>
      
      <div>
        <label htmlFor="recipients">Recipients (comma-separated):</label>
        <input
          type="text"
          id="recipients"
          value={formData.recipients}
          onChange={(e) => setFormData({...formData, recipients: e.target.value})}
          placeholder="admin@example.com, user@example.com"
          required
        />
      </div>
      
      <div>
        <label htmlFor="threshold">Threshold:</label>
        <input
          type="number"
          id="threshold"
          value={formData.threshold}
          onChange={(e) => setFormData({...formData, threshold: e.target.value})}
          required
        />
      </div>
      
      <div>
        <label htmlFor="operator">Operator:</label>
        <select
          id="operator"
          value={formData.operator}
          onChange={(e) => setFormData({...formData, operator: e.target.value})}
        >
          <option value="GREATER_THAN">Greater Than</option>
          <option value="LESS_THAN">Less Than</option>
          <option value="EQUALS">Equals</option>
        </select>
      </div>
      
      <button type="submit" disabled={loading}>
        {loading ? 'Creating...' : 'Create Alert'}
      </button>
    </form>
  );
}

async function getPaginatedAlerts(page = 0, size = 20, sort = 'createdAt,desc') {
  const response = await fetch(
    `/alerts/api/v1?page=${page}&size=${size}&sort=${sort}`,
    {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    }
  );

  if (!response.ok) {
    throw new Error('Failed to fetch alerts');
  }

  return await response.json();
}

// Usage with pagination
let currentPage = 0;
const pageSize = 10;

async function loadNextPage() {
  try {
    const data = await getPaginatedAlerts(currentPage, pageSize);
    console.log(`Page ${currentPage + 1}:`, data.content);
    
    if (!data.last) {
      currentPage++;
    }
  } catch (error) {
    console.error('Error loading page:', error);
  }
}

Rate Limiting and Retry Logic​

class AlertAPIClient {
  constructor(token, baseURL = '/alerts/api/v1') {
    this.token = token;
    this.baseURL = baseURL;
    this.retryAttempts = 3;
    this.retryDelay = 1000; // 1 second
  }

  async request(endpoint, options = {}) {
    const url = `${this.baseURL}${endpoint}`;
    const config = {
      headers: {
        'Authorization': `Bearer ${this.token}`,
        'Content-Type': 'application/json',
        ...options.headers
      },
      ...options
    };

    for (let attempt = 0; attempt < this.retryAttempts; attempt++) {
      try {
        const response = await fetch(url, config);
        
        if (response.status === 429) {
          // Rate limited - wait and retry
          const retryAfter = response.headers.get('Retry-After') || 60;
          await this.delay(retryAfter * 1000);
          continue;
        }
        
        if (!response.ok) {
          throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }
        
        return await response.json();
      } catch (error) {
        if (attempt === this.retryAttempts - 1) {
          throw error;
        }
        
        // Exponential backoff
        await this.delay(this.retryDelay * Math.pow(2, attempt));
      }
    }
  }

  delay(ms) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }

  async createAlert(alertData) {
    return this.request('', {
      method: 'POST',
      body: JSON.stringify(alertData)
    });
  }

  async getAlerts(page = 0, size = 20) {
    return this.request(`?page=${page}&size=${size}`);
  }

  async getAlert(id) {
    return this.request(`/${id}`);
  }

  async updateAlert(id, alertData) {
    return this.request(`/${id}`, {
      method: 'PUT',
      body: JSON.stringify(alertData)
    });
  }

  async deleteAlert(id) {
    return this.request(`/${id}`, {
      method: 'DELETE'
    });
  }
}

// Usage
const client = new AlertAPIClient('your-jwt-token');

client.createAlert({
  name: 'Test Alert',
  description: 'Test alert description',
  recipients: ['test@example.com'],
  scheduleType: 'CRON',
  cronExpression: '0 */5 * * * *',
  sourceType: 'TEST',
  sourceId: 'test_metric',
  config: {
    threshold: 100,
    operator: 'GREATER_THAN'
  }
})
.then(alert => console.log('Alert created:', alert))
.catch(error => console.error('Error:', error));
