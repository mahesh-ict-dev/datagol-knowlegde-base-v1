NoCoDB v3 APIs

Authentication​

All v3 APIs require JWT authentication via the s_jwt security requirement.

Core APIs​

BI v3 API​

Base Path: noCo/api/v3/workspaces/{workspaceId}/bi

MethodEndpointDescription
GET/Get BI configuration
PUT/{id}Modify BI
DELETE/{id}Delete BI
POST/{biId}/interfacesCreate interface
PUT/{biId}/interfaces/{id}Update interface
DELETE/{biId}/interfaces/{id}Delete interface
POST/{biId}/interfaces/{interfaceId}/pagesCreate interface page
PUT/{biId}/interfaces/{interfaceId}/pages/{id}Update interface page
DELETE/{biId}/interfaces/{interfaceId}/pages/{id}Delete interface page
GET/{biId}/interfaces/{interfaceId}/pages/{pageId}/config/{id}Get interface page config
PUT/{biId}/interfaces/{interfaceId}/pages/{pageId}/config/{id}Update interface page config
POST/{biId}/interfaces/{interfaceId}/pages/{pageId}/config/{configId}/widgetsCreate interface page config widget
PUT/{biId}/interfaces/{interfaceId}/pages/{pageId}/config/{configId}/widgets/{id}Update interface page config widget
DELETE/{biId}/interfaces/{interfaceId}/pages/{pageId}/config/{configId}/widgets/{id}Delete interface page config widget

Key Features​

Advanced BI Capabilities​

  • Interface Management: Create and manage multiple BI interfaces
  • Page Configuration: Advanced page-level configuration options
  • Widget Management: Enhanced widget configuration and management
  • Hierarchical Structure: BI → Interface → Page → Config → Widget hierarchy

Enhanced Architecture​

  • Workspace-based: All operations are scoped to workspaces
  • Modular Design: Clear separation of concerns between interfaces, pages, and widgets
  • Scalable: Support for multiple interfaces and complex configurations

Usage Examples​

Creating a BI Interface​

curl -X POST "noCo/api/v3/workspaces/{workspaceId}/bi/{biId}/interfaces" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sales Dashboard Interface",
    "description": "Interface for sales analytics dashboard",
    "type": "DASHBOARD",
    "config": {
      "theme": "light",
      "layout": "grid"
    }
  }'

Creating an Interface Page​

curl -X POST "noCo/api/v3/workspaces/{workspaceId}/bi/{biId}/interfaces/{interfaceId}/pages" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sales Overview",
    "description": "Sales overview page",
    "layout": "GRID",
    "position": 1
  }'

Creating a Widget Configuration​

curl -X POST "noCo/api/v3/workspaces/{workspaceId}/bi/{biId}/interfaces/{interfaceId}/pages/{pageId}/config/{configId}/widgets" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sales Chart",
    "type": "CHART",
    "config": {
      "chartType": "BAR",
      "dataSource": "sales_table",
      "dimensions": ["region"],
      "measures": ["sales_amount"]
    },
    "position": {
      "x": 0,
      "y": 0,
      "width": 6,
      "height": 4
    }
  }'

Updating BI Configuration​

curl -X PUT "noCo/api/v3/workspaces/{workspaceId}/bi/{biId}" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated BI Configuration",
    "description": "Updated description",
    "settings": {
      "autoRefresh": true,
      "refreshInterval": 300
    }
  }'

Migration from v2​

Key Differences​

  1. Hierarchical Structure: v3 introduces a clear hierarchy (BI → Interface → Page → Config → Widget)
  2. Interface Management: Multiple interfaces per BI configuration
  3. Enhanced Widgets: More sophisticated widget configuration options
  4. Better Organization: Improved separation of concerns

Migration Steps​

  1. Create BI Configuration: Set up the main BI configuration
  2. Create Interfaces: Define interfaces for different use cases
  3. Create Pages: Organize content into pages within interfaces
  4. Configure Widgets: Set up widgets with enhanced configuration options

Example Migration​

From v2 BI Page:

# v2 - Direct page creation
POST /noCo/api/v2/workspaces/{workspaceId}/biPage

To v3 BI Interface Page:

# v3 - Create interface first, then page
POST /noCo/api/v3/workspaces/{workspaceId}/bi/{biId}/interfaces
POST /noCo/api/v3/workspaces/{workspaceId}/bi/{biId}/interfaces/{interfaceId}/pages
