# Selecting a Workbook

To begin visualizing data, you first need to select a workbook.

## How to Add or Select a Workbook

1. On the **Home** page, use the left navigation panel to click **Workspace**.
2. From the list of available workspaces, select the one you want to work with.
3. At the top, click **Visualizer**.
4. Choose the required workbook from the list to get started.

<ImagePopup src="/img/select-worbook.gif" alt="Visualizer Home" caption="Visualizer Home" style={{ width: '50px' }} />

## Types of Workbooks

- **Workspace Workbooks:** Regular workbooks added directly to your workspace.
- **BI Workbooks:** Specialized workbooks designed for Business Intelligence use cases.
