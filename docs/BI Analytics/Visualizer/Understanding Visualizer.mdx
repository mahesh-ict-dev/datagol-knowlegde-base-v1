 This topic introduces the user interface (UI) for data visualization. It describes the individual components of the visualizer's interface and explains the function of each part. Each of the functions are referenced to the corresponding topics. 
  
  <ImagePopup src="/img/visualizer.png" alt="Visualizer Home" caption="Visualizer Home" />

  |No.| Item| Description| Reference|
  |:---:|:----|:---|:---|
 |1| **Workbook selection**|From the Workspaces, either select or add a workbook to begin your analysis. |[How to add a workbook](/docs/BI%20Analytics/Visualizer/Select%20workbook)|
   |2|**Auto-populated columns**|Columns from the selected workbook are automatically displayed for selection.||
   |3|**Column selection**|Add columns to the search bar to include them in your visualization.|[Learn more about selecting columns](/docs/BI%20Analytics/Visualizer/Select%20Columns)
   |4|**Visualization type**| Easily switch between different visualization types (e.g., bar, pie, line) to best represent your data.|[Learn more about visualization types](/docs/BI%20Analytics/Widgets/Widget%20Types)|
   |5|**Configuration panel**|Fine-tune your widget’s configuration.|[Widget types and configurations](</docs/BI Analytics/Widgets/Widget configurations and settings/Widget Configuration and Settings.mdx>)|
   |6|**Settings panel**| Modify the widget’s title, subtitle, and help message for better understanding.|[Widget types and configurations](</docs/BI Analytics/Widgets/Widget configurations and settings/Widget Configuration and Settings.mdx>)|
   |7|**Drill-down** |Configure drill-down layers to explore data in more detail. |[Learn about drill-down](/docs/BI%20Analytics/Drill%20Down)|
   |8|**Details panel**|View the SQL query behind your widget for transparency and troubleshooting. |[Learn about Details panel](/docs/BI%20Analytics/Visualizer/Details%20Panel)|
   |9|**Add formulas**|Create custom formulas for advanced BI calculations.|[Understanding formulas on BI](/docs/BI%20Analytics/Formulas%20&%20Parameters/BI%20Formula)|
   |10|**Add parameters**|Use parameters to make your BI platform more dynamic and interactive.|[Understanding parameters on BI](/docs/BI%20Analytics/Formulas%20&%20Parameters/Parameters)|
   |11|**Save widget/visualization** |**Pin to dashboard:** Add your widget to a dashboard for easy access. **Save as draft:** Save your work-in-progress for later editing.|[Learn about pinning a visualization](/docs/BI%20Analytics/Visualizer/Save%20Widget/Pin%20to%20Dashboard), [Learn about creating drafts](/docs/BI%20Analytics/Visualizer/Save%20Widget/Save%20As%20Draft)|
