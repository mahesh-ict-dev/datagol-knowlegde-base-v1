1.  **Select a workbook** to visualize data. You can choose one of the following types of workbooks:    

    - **Workspace workbooks:** Regular workbooks added directly to your workspace.
    - **BI workbooks:** Specialized workbooks designed for Business Intelligence use cases.
    
        For more details refer to [BI Workbooks](/docs/BI%20Analytics/BI%20Workbook.mdx).

    Do the following to select a workbook:
    1. On the **Home** page, from the left navigation panel, click **Workspace**.
    2. From the list of available workspaces, select a workspace. 
    3. At the top, click **Visualizer**.
    4. Choose the required workbook from the list.

    <ImagePopup src="/img/select-worbook.gif" alt="Visualizer Home" caption="Visualizer Home"  />
    
3.  **Add columns to visualize**. All the columns of the workbook are listed in the left navigation panel. Select the columns from the left navigation panel, which also gets populated on the **Search** bar.

    <ImagePopup src="/img/select-workbook-search.png" alt="select columns" caption="select columns" />

    Another method to select columns is by typing the column name on the search bar, this displays a drop-down menu on the corresponding columns in auto complete mode.

    <ImagePopup src="/img/search_bar.png" alt="create-visualization1" caption="create-visualization1"  style={{ width: '50px' }} />

    The columns are listed with color codes:

    -   **Blue**: These columns contain numerical data that can be aggregated by summing their values.

        <ImagePopup src="/img/image-20250503-125233.png" alt="create-visualization2" caption="create-visualization2"  style={{ width: '50px' }} />

    -   **Purple**: These columns contain data, either numerical or textual, that are not suitable for summation or similar mathematical aggregation.

        <ImagePopup src="/img/image-20250508-111408.png" alt="create-visualization3" caption="create-visualization3" style={{ width: '50px' }} />

    -   **Grey**: These columns contain date and time-based data.

         <ImagePopup src="/img/image-20250503-130028.png" alt="create-visualization4" caption="create-visualization4" style={{ width: '200px' }} />

    For more details refer to [selecting columns](/docs/BI%20Analytics/Visualizer/Select%20Columns).

5.  From the upper right side, choose the appropriate aggregation functions for each columns. Refer to [Aggregate functions](</docs/BI Analytics/Visualizer/Aggregate functions.mdx>)
    <ImagePopup src="/img/image-20250509-104554.png" alt="create-visualization6" caption="create-visualization6" />

6.  Click **Create Now** or from top, click **Generate**. The most appropriate visualization widget for your selected data is displayed on the canvas.
    
7.  From the right of the page you have multiple edit options.
    
    <ImagePopup src="/img/image-20250503-171422.png" alt="create-visualization7" caption="create-visualization7" /> 
 
    Click the any of following icons to:
    
    -   Change the visualization/widget type. Click the **Change Visualization/ Widget type** icon to get this done.  
        
        <ImagePopup src="/img/image-20250503-171422.png" alt="create-visualization8" caption="create-visualization8" /> 
        
    -   Edit the configurations of the current widget. To do this click the **Update Widget Column Configurations** icon.  
          
         <ImagePopup src="/img/image-20250503-170512.png" alt="create-visualization9" caption="create-visualization9" /> 
        
    -   Edit the settings of the current widget. To do this click the **Update Settings** icon.
        
         <ImagePopup src="/img/image-20250503-170524.png" alt="create-visualization10" caption="create-visualization10" />
        
    -   Choose drill down options to drill down the data. To do this click the **Drill Down** icon.  
          
        <ImagePopup src="/img/image-20250503-170538.png" alt="create-visualization11" caption="create-visualization11" />
        
    -   View SQL query of the data visualization details. To do this, click the **View Data Details** icon. Refer [Viewing the Data Details panel](</docs/BI Analytics/Visualizer/Details Panel.mdx>)
        
        <ImagePopup src="/img/image-20250503-170858.png" alt="create-visualization11" caption="create-visualization11" />
        
8.  Ensure to save the widget to a dashboard. Refer to [creating a dashboard](https://saasxl.atlassian.net/wiki/spaces/DD1/pages/413106180/Visualizer+Dashboards+Guide#Creating-dashboards "https://saasxl.atlassian.net/wiki/spaces/DD1/pages/413106180/Visualizer+Dashboards+Guide#Creating-dashboards").
