Visualizer is a data visualization tool that allows you to model data from workbooks and create a variety of widgets, including Bar, Line, Area, Scatter, Packed Bubble, Pie, Donut, Funnel, Tree map, Box plot, Tables, and Pivot Tables including those with Tree views.

Visualizer intelligently suggests the best widget for your selected data, offers extensive customization, and enables data exploration through regular, column, or widget drill-down. These widgets can be pinned onto interactive dashboards that can be embedded into other applications with data refresh capabilities.
