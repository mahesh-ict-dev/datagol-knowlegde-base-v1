Once the workbook is selected, the next step is to identify and add the desired columns to be visualized.
All the columns of the workbook are listed in the left navigation panel. The columns are listed with color codes:

<ImagePopup src="/img/visualizer_columns.png" alt="create-visualization1" caption="create-visualization1"  style={{ width: '50px' }} />


    -   **Blue**: These columns contain numerical data that can be aggregated by summing their values.

        <ImagePopup src="/img/image-20250503-125233.png" alt="create-visualization2" caption="create-visualization2"  style={{ width: '50px' }} />

    -   **Purple**: These columns contain data, either numerical or textual, that are not suitable for summation or similar mathematical aggregation.

        <ImagePopup src="/img/image-20250508-111408.png" alt="create-visualization3" caption="create-visualization3" style={{ width: '50px' }} />

    -   **Grey**: These columns contain date and time-based data.

         <ImagePopup src="/img/image-20250503-130028.png" alt="create-visualization4" caption="create-visualization4" style={{ width: '200px' }} />

    You can select these columns from the left navigation panel, which populates these columns on the **Search** bar

Another method to select columns is by typing the column name on the search bar, this would show a drop down on suitable columns in auto complete mode.

  <ImagePopup src="/img/search_bar.png" alt="create-visualization1" caption="create-visualization1"  style={{ width: '50px' }} />


The next step is to choose the appropriate aggregation functions for each column. Refer to [Aggregate functions](/docs/BI%20Analytics/Column%20Aggregation.mdx) for more details.

<ImagePopup src="/img/image-20250509-104554.png" alt="create-visualization6" caption="create-visualization6" style={{ width: '200px' }} />

You can click **Create Now** or from top click **Generate**. The most appropriate visualization widget for your selected data is displayed on the canvas.
