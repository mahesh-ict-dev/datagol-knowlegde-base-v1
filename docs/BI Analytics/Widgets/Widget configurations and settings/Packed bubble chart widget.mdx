## Configuring Packed Bubble chart widget

To configure Packed bubble chart widget do the following:

1.  From the right side of the widget generation page, click the **Update Widget Column Configurations** icon.

2.  Configure any of the following:

    | Items | Description |
    |:---|:---|
    | **Categories** | Click the field to change the title of the categories. |
    | **Size** | Click the field and specify the following:<ul><li>**Title**: Change the title of the Packed Bubble chart widget.</li><li>Toggle **Chart Data Label** to change the color of the labels within the bubbles.</li><li>**Top/Bottom analysis** pinpoints the highest (Top) or lowest (Bottom) performers within a dataset based on a chosen metric, displaying a specified number (N) of these entities for focused insights. You can set the direction which can be top or bottom and provide the number limit.</li><li>Choose an option from the **Numeric Notions** to select how numerical values are displayed:</li><ul><li>**Auto:** The system automatically determines the most appropriate notation (standard, thousands, millions) based on the magnitude of the data.</li><li> **Thousands (K):** Displays values in thousands, abbreviated with K (e.g., 10,000 becomes 10K).</li><li>**Millions (M):** Displays values in millions, abbreviated with M (e.g., 1,000,000 becomes 1M).</li></ul><li>In **Decimal**, specify the number of digits to display after the decimal point.</li></ul> |


## Setting Packed Bubble chart widget

To set the Packed Bubble chart widget, do the following:

1.  From the right side of the widget generation page, click the **Update settings** icon.

2.  Set the following:

   | Item | |Description |
    |:---|:---|:----|
    | **General** | |Set general details. |
    | |**Title** | Edit the **title** of the chart. |
    | |**Subtitle** | Edit the **subtitle** of the chart. |
    | |**Help message** | Type the message that appears when you hover over the **help icon**. |
    | **Tooltip** | |Check this option for the chart **tooltip** and choose either to share all values in a single tooltip, or show each point's value separately. |
    | **Linked reports** | |Set the details of the dashboard reports you want to view from this widget. |
    | |**Linked report URL** | Paste the **URL** of the dashboard that you want to view from this widget. |
    | |**Open in New tab** | Specify if you want to view the linked report in a **different tab**. |
