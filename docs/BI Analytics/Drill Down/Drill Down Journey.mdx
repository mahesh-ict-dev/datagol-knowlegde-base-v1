## What is Drill Down Journey?

The Drill Down Journey feature enhances the existing Drill Down functionality by allowing users to configure and predefine the drill-down experience. You can specify the behavior, structure, and visualization of each drill-down step, ensuring a more tailored and controlled data exploration process.

<ImagePopup src="/img/ddj.png" alt="drill-down-column-drill-down-widget-drill-down1" caption="drill-down-column-drill-down-widget-drill-down1" />

The defined multi-step drill-down paths in your widgets can be later retraced from the Dashboards. **Drill Down Journeys** are available on the widgets which are saved and pinned to a dashboard.


With the **Drill Down journey**, you can:

-   Define specific drill-down steps, including the columns to drill into, time buckets (for time-based data), and the desired chart types at each step.

-   Create complex drill-down paths with an unlimited number of steps, enabling deep data exploration and analysis.



### How to configure Drill Down Journey?

1.  **Define the Journey:** While creating a widget from the visualizer, click the **Drill Down Journey** icon on the right side panel and enable the Drill Down Journey to define the steps, specifying the columns, time buckets, and chart types for each step.

    <ImagePopup src="/img/visualizer/drill-down-journey.gif" alt="drill-down-column-drill-down-widget-drill-down1" caption="drill-down-column-drill-down-widget-drill-down1" />

2.  **Pin to Dashboard:** Save the changes and pin the chart to a dashboard.

3.  **Explore the Data:** On the dashboard, initiate the Drill Down Journey and retrace the defined steps to explore your data in detail.

## When to use Drill-Down Journey?

 - Ideal for structured, hierarchical exploration
  Use when you want users to follow a predefined path — for example: Country → State → City → Region. This ensures consistency in how data is explored across users.

 - Simple to configure and manage
  Drill-down journeys can be easily set up through the visual interface without writing code or creating separate widgets.

 - Accessible to non-technical users
  Designed with simplicity in mind, it allows business users to configure and use drill paths without requiring advanced technical skills.
