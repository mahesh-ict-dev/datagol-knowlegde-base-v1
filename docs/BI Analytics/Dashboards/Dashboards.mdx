Dashboards are interactive visual interfaces that consolidate and present key data points in a clear, accessible format. They enable users to monitor performance, uncover trends, and make informed decisions by visualizing complex datasets through charts, tables, and key performance indicators (KPIs).

# Creating a dashboard

Within each workspace along with Workbooks there are two modules for BI: **Visualizer** and **Dashboards**.
Each dashboard is independent to that workspace until [externally shared](/docs/BI%20Analytics/Sharing/External%20Dashboards).

To Create a new page, on the Dashboard section on the bottom left there is option to create new page.
<ImagePopup src="/img/create-new-dashboard.gif" alt="switch-workbooks-in-a-dashboard" caption="dashboard" />

You can start creating widgets from 'Create Widget' option available on dashboard or create widgets directly from the visualizer to then pin it to the respective dashboard pages
# Editing Dashboard:

on the top right there is a gear icon,from here we can manage/ edit the Dashboard

 ## Editing Widgets on a Dashboard
   In the setting panel select the second option that says :
-> "Manage Layout and Widgets"
now hover over any widget that you want to edit and select the edit icon under that widget
by selecting edit , a pop up comes where it goes into edit mode of the visualizer , make changes to your chart and hit 'Save' option on the chart
<ImagePopup src="/img/manage-layouts.gif" alt="/img/create-new-dashboard.gif" caption="dashboard" />

User can also **re arrange** or edit the size of the layout of the widget by simply dragging and dropping to necessary size and place

**Duplicating widgets** If you like any widget but want to make minimal changes on it and need a copy of the widget , you can simply select the Duplicate widget option and later edit from the edit mode.


# Understanding Icons on Widget on a Dashboard:

<img src="/img/Icons-image.png" alt="dashboard" style={{ width: '300px' }} />

### 1) Linked Report:
 You can add a link/ URL to any dashboard page / workbook / Report that would give more insights about the data being pulled
### 2) Help Message:
 On each widget you can add a small help text that give a short description about the widget. You can configure this from the visusalizer while creating widget or from edit mode as well.
 on the settings panel of each widget under the title and subtitle , we can include the Help Message.
### 3) Explore Mode:
 Explore mode on a widget helps you get a more focused view of the widget , on this mode by default on the right hand side there are a list of auto populated / system geenrated filters that the user can add. additionally he can also choose these manually from choose filter option on the top right.
 - you can also [Drill Down](/docs/BI%20Analytics/Drill%20Down/Drill%20Down.mdx) on the widgets from this view
 - Show Point Data :
 on the right click on a particular point and select show point data option from the list , this will show all the indiviual records of the dataset leading to the final value that we see on the widget
 -Show Raw Data:
 once you do the right click on the widget there is another option called Show Raw Data , this would show all the records of the workbook powering this widget
 - Show as Table:
 Using this option , the user can see the content of the data that he is seeing on the visual in the form of a tabular representation
 - Undo / Redo / Reset:
 on the top right of the explore mode on the widget , there are three options :
  - undo : whatever current change made is lost and user is navigated to the prior screen
  - redo : helps in redo / go to the next step user had already performed
  - reset: helps in taking the widget visual to the original form
 Note : Any changes made on the explore mode of the widget are just for deeper analysis purpose to slice and dice the data better , hence these changes will not be saved / retained on the original widget
### 4) [Widget Level Filter](/docs/BI%20Analytics/Widgets/Widget%20Filters.mdx) :
Hovering on this icon will show the list of all the widget level filters that were added on this widget from the visualizer.
### 5) [Page Level Filter](/docs/BI%20Analytics/Dashboards/Page%20Filter.mdx) :
Hovering on this icon displays the list of page level filters that were configured and applied to this widget from the dashboard page.

Note : Incase there is a page level and widget level filter applied on the same column on a widget , then the Widget level filter takes precedence over the selection on the page level filter for the same column.

### 6) Show SQL :
at any point you would like to understand the underlying query powering this widget , you can select the show SQL , this explains about the page level / widget level filters being applied , any formula column or parameter currenlty being rendered on this widget.
Note: this is just a view only option , user will not be able to edit query from here to modify the widget.



# Switch Workbook:

If you want to replace the existing workbook powering the widgets on the dashboard with a new workbook from within the workspace , you can use the 'Switch Workbook' option.
Understand the impact , make sure that there are relevant columns matching to ensure that the dashboard doesnt break due to loss in columns / information.
