You can link the dashboard reports you want to view from within a widget.

1.  On the **Home** page, from the left navigation panel, click **Workspace** and  from the list of workspaces, select a workspace from where you want to visualize data.
    
2.  From the top, click **Visualizer** and generate a widget.
    
3.  From the right side of the widget generation page, click the **Update settings** icon.
    ![linking-dashboards](/img/visualizer/image-20250503-170524.png)
    
4.  Set the following:
    
    -   **Linked Report URL**: Copy and paste the link of a dashboard that you want to link from within a widget.
        
    -   **Open in New Tab**: Specify, if you want to view the linked report in a different tab.  
        A link icon is displayed on top. Clicking the icon takes you to the Dashboard.
        
        ![linking-dashboards](/img/visualizer/image-20250514-140310.png)
