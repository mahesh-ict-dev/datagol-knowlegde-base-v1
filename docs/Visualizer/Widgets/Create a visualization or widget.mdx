1.  On the **Home** page, from the left navigation panel, click **Workspace** and  from the list of workspaces, select a workspace from where you want to visualize data.
    
2.  From the top, click **Visualizer**.
    
    ![create-visualization1](/img/image-20250503-124146.png)
    
3.  From the dropdown on top, choose a specific workbook containing the data you wish to visualize. All the columns of the workbook are listed in the left navigation panel. The columns are listed with color codes:
    
    -   **Blue**: These columns contain numerical data that can be aggregated by summing their values.
        
        ![create-visualization2](/img/image-20250503-125233.png)
    
    -   **Purple**: These columns contain data, either numerical or textual, that are not suitable for summation or similar mathematical aggregation.
        
        ![create-visualization3](/img/image-20250508-111408.png) 
        
    -   **Grey**: These columns contain date and time-based data.
        
         ![create-visualization4](/img/image-20250503-130028.png) 
        
4.  Choose the columns containing the data you want to visualize. These columns are listed horizontally on the top.
    
5.  From the upper right side, choose the appropriate aggregation functions for each columns. Refer to [Aggregate functions](https://saasxl.atlassian.net/wiki/spaces/documentation/pages/392527873/Data+visualization+guide#Aggregate-functions "https://saasxl.atlassian.net/wiki/spaces/documentation/pages/392527873/Data+visualization+guide#Aggregate-functions") for more details.
    
    ![create-visualization6](/img/image-20250509-104554.png)

6.  Click **Create Now** or also click **GO** from top. The most appropriate visualization widget for your selected data is displayed on the canvas.
    
7.  From the right of the page you have multiple edit options.
    
    ![create-visualization7](/img/image-20250503-171422.png) 
 
    Click the any of following icons to:
    
    -   Change the visualization/widget type. Click the **Change Visualization/ Widget type** icon get this done.  
        
        ![create-visualization8](/img/image-20250503-171422.png) 
        
    -   Edit the configurations of the current widget. To do this click the **Update Widget Column Configurations** icon.  
          
         ![create-visualization9](/img/image-20250503-170512.png) 
        
    -   Edit the settings of the current widget. To do this click the **Update settings** icon.
        
         ![create-visualization10](/img/image-20250503-170524.png)
        
    -   Choose drill down options to drill down the data. To do this click the **Drill Down** icon.  
          
        ![create-visualization11](/img/image-20250503-170538.png)
        
    -   View SQL query of the data visualization details. To do this, click the **View Data Details** icon.
        
        ![create-visualization11](/img/image-20250503-170858.png)
        
8.  Ensure to save the widget to a Dashboard. Refer to [creating a dashboard](https://saasxl.atlassian.net/wiki/spaces/DD1/pages/413106180/Visualizer+Dashboards+Guide#Creating-dashboards "https://saasxl.atlassian.net/wiki/spaces/DD1/pages/413106180/Visualizer+Dashboards+Guide#Creating-dashboards").
