# Connect Confluence
 
Index pages and spaces from your Confluence wiki.
 
## Steps
 
### 1. Authorize access *(Required)*
- Enter a **Connection name** (e.g. "Confluence Connector")
- Click **Connect with Confluence** to authenticate via OAuth
### 2. Choose what to sync
- **Sync Specific Spaces** *(Required)* — add one or more page or space URLs (e.g. `https://your-domain.atlassian.net/wiki/spaces/...`)
- Use **+ Add Folder URL** to include additional spaces
- Use the trash icon to remove an entry from the list
### 3. Initial Sync
- Optionally check **Start syncing right after connecting** to begin indexing immediately upon setup
### 4. Save
- Click **Save connector** to complete setup, or **Cancel** to discard
