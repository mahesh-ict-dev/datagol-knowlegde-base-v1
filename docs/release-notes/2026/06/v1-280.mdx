**Date released: June 4, 2026**


## Enhancements

### AI
- **Motion MCP Connector Integration for Custom Agents:** Custom Agents now support the Motion MCP connector. Users can create a Motion MCP connector and attach it directly to a Custom Agent during agent creation or configuration. Once connected, the agent answers questions about the user's Motion workspace by making MCP tool calls and generating responses from the returned data. Motion MCP tools are fully available to the agent, and tool call errors are handled gracefully.


## Bug Fixes

- Fixed an issue where the Hubspot agent would repeat tool calls multiple times and intermittently return "An error occurred while processing the request" when a thread was shared at the company level or internally shared with editor role access. The agent now responds correctly and efficiently on shared threads.
- Fixed a performance issue where the Python Agent experienced very long response delays when a thread was shared at the company level or internally with editor role, and the auto-suggestion toggle was disabled. After asking a question and providing feedback on the shared thread, the agent now responds in a timely manner.
- Fixed a bug where Custom Agents using the Motion MCP Connector were returning results in an error format for certain sets of questions. The agent now processes Motion MCP tool calls correctly and returns proper responses.
