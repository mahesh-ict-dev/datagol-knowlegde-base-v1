### External Dashboard Improvements

Following improvements have been done for External Dashboards, improving the experience for users accessing dashboards across companies.

- **Filter Support** – Users can now successfully add and apply filters on shared External Dashboards.
- **Show as Table** – The **Show as Table** option now correctly displays widget data in a tabular format.
- **Widget Data Download** – Downloading widget data from shared External Dashboards now works as expected.
