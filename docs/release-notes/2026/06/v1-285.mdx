**Date released: June 8, 2026**


## Enhancements
### AI

- **More model choice with OpenRouter** You can now use OpenRouter to access open-source models like DeepSeek and Qwen. This gives your team more flexibility to choose the right model for different use cases, costs, and performance needs.
<ImagePopup src="/img/release_notes/2026/2026/June/openrouter.png" alt="Open Router" caption="Open Router" />

- **Better visibility into Custom Agent usage:** Custom Agent Analytics now shows the top users by tokens, requests, and cost. This makes it easier to understand usage patterns, monitor spend, and identify where to optimize agent activity.
<ImagePopup src="/img/release_notes/2026/2026/June/cos.png" alt="Custom Agent Analytics" caption="Custom Agent Analytics" />

- **More charting and analysis in D.A.V.E:**  D.A.V.E. now handles chart creation and data analysis more reliably, with better support for advanced visuals like heatmaps and clearer handling of chart requirements such as sunburst views. These improvements help users get the right visualization faster and reduce errors when working with more complex requests.

### Workspaces & Workbooks
- [Workbook Data Enrichment with DataBar AI](/docs/Workbooks/workbook-columns#workbook-data-enrichment-with-databar) Workbooks now support DataBar-powered enrichment, allowing you to enrich your data using providers like Google Maps, Diffbot, and People Data Labs directly within your workbook. Map inputs, select output fields, and run enrichments on individual rows, selected rows, or the full workbook.
