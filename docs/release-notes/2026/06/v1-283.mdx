## Enhancements
### BI

- **Multi-Page External Dashboard Embedding:** DataGOL now supports embedding multiple dashboard pages from a workspace together via the External Dashboard option. 
Previously, only a single dashboard page could be embedded at a time. With this update, you can bundle multiple pages into one external dashboard link, allowing end users to navigate between pages within the embedded view , just as they would inside DataGOL. This is ideal for client-facing portals or internal tools where users need access to several related dashboards without switching between separate embed links.
