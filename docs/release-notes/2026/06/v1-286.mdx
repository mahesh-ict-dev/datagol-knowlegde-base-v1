**Date released: June 11, 2026**


## Enhancements
### AI

- **Smarter tables and more dependable visualizations in D.A.V.E:** D.A.V.E. now creates tables and charts more intelligently, with better default behavior for sorting, pinned columns, heatmaps, and data bars. This means users get clearer, more polished outputs automatically, even when they do not specify every formatting detail.

## Bug Fixes
- Resolved an issue where the Data Science Agent could appear stuck on “Thinking” and end with “Failed to send response,” even though the answer was generated successfully in the background. Responses now stream and render properly in the UI, so users can see results without needing to refresh the page.
