**Date released: April 30, 2026**


## New Features and Enhancements

### AI

- **GTM Agent ICP to Company List and People List Flow:** The GTM Agent backend has been extended to support an ICP (Ideal Customer Profile) driven research flow. When a user executes ICP research from the Chrome Extension, the agent now processes and routes the output into structured Company List and People List workbooks, enabling downstream usage for targeting, indexing, and further agent-based analysis.
- **GTM ICP Research UI:** The GTM Agent Chrome Extension and settings page have been enhanced to support ICP-driven research. Users can now define and save an ICP prompt under the GTM Agent settings, then select ICP as a research type directly from the extension. When selected, the extension automatically fetches the saved ICP prompt and executes the research without requiring manual input, with results written to a structured workbook for further use.
- **PDF Download Button Discoverability in Agent Chat:** The PDF download experience within the agent chat interface has been improved. Previously, the download action was represented by a minimal icon-only button inside the right-hand PDF viewer panel, making it difficult to discover. The button has been given a clearer label and improved visual prominence so users can easily identify and access the download action without relying on icon interpretation.
