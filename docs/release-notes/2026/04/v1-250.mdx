**Date released: April 1, 2026**


## New Features and Enhancements

### Lakehouse
- Users can now connect **Supabase** as a data source. Simply provide your connection details including host, port, credentials, and schema to get started.

### Workspace
- **File URL Redirect in Extraction Tracker:** Workspace ID is now visible in the extraction tracker for better traceability. Clicking the File URL now redirects users directly to the corresponding context document.

### Onboarding

- **Sign In with Microsoft:** Users can now sign in using their Microsoft account, similar to the existing Google sign-in option. New users are automatically onboarded with an account, while existing users are redirected straight to the home page upon login.

### AI

- **Stop or Cancel a Question Being Processed by the AI Agent** Users can now interrupt and cancel a question that the AI Agent is actively working on, without needing to wait for it to finish or refresh the page.


## Bug Fixes

- Fixed an issue where the Select All and Deselect All buttons were not functioning on the Atlassian Agent's MCP tool configuration page.
Users can now properly select or clear all tools at once when configuring the Atlassian Agent.
