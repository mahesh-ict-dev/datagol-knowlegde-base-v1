**Date released: April 17, 2026**


## New Features and Enhancements

### AI

- **Data Science Agent - Multi-Dataset Analysis:** Enabled support for multiple datasets in a single chat, allowing users to load and analyze additional workbooks alongside the main dataset for cross-table analysis and comparisons.
ds_multi_wb.png
<ImagePopup src="/img/AI/ds_multi_wb.png" alt="Multi Wb" caption="Multi Wb" />
- **Custom Agent – Unsaved Changes Protection:** Added a guard to prevent users from leaving pages with unsaved changes in Custom Agent forms, helping avoid accidental data loss.

### Workbooks

- **Allow clearing a date cell in workbooks:** Enable users to clear an already-set date value in the grid date editor, by setting the underlying cell value to null.
