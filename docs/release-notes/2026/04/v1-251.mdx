## New Features and Enhancements

### BI

#### New Charts

- **Radial Chart:** Compare multiple categories on a circular axis for quick visual ranking and proportional insights.
- **Radar Chart:** Plot multi-dimensional metrics across months or categories using an intuitive spider-web layout.
- **Sunburst Chart:** Explore hierarchical data with interactive drill-down navigation, from region to category to subcategory.
- **Cohort Analysis:** Build retention heatmaps to track how user groups behave and engage over time.
- **Top N / Bottom N on Grouped Charts:** Instantly filter grouped charts to surface only the highest or lowest performing segments.

#### New Feature

- **LOD (Level of Detail)** lets you compute a metric at a different grouping level than your chart — without changing the chart's existing grouping or layout.
For example, you can show total sales by category while simultaneously calculating each category's share of the grand total, a value computed across all data.
This makes it possible to blend chart-level and dataset-level calculations in a single visualization.
