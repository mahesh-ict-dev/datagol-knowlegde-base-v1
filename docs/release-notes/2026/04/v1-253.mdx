## New Features and Enhancements

### AI

- **HubSpot Agent Released with Alpha Tag:** The HubSpot Agent is now available with an Alpha tag, indicating it is in early access for initial testing and feedback.

## Bug Fixes

- **Improved Handling of Nested Structures in MongoDB Ingestion:** Fixed an issue where NULL values inside complex nested structures were not resolved correctly during schema inference in MongoDB ingestion.
The fix introduces recursive traversal to properly handle void and ambiguous data types at all levels of nested structs in MultiCatalog.
