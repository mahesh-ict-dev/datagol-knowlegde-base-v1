## Enhancements

### AI
- **Cloud Storage Agnostic Support for Custom Agent Skills:** Custom Agent skills have been updated to support multiple cloud storage providers. Previously, agent skills were exclusively stored in AWS S3. Following the GCP migration, the storage layer has been refactored to be fully storage-agnostic, now supporting:
Google Cloud Storage (GCS), Microsoft Azure Blob Storage and Amazon S3
