**Date released: May 21, 2026**


## Enhancements

### AI
- **Custom Agent Sharing - Service Account Support:** Custom agents can now be shared with Service Accounts. Previously, agent sharing was limited to individual user accounts. This enhancement allows platform and integration teams to assign custom agents to service accounts, enabling automated workflows, system-to-system integrations, and programmatic agent access without relying on individual user credentials.

### Workbooks
- Added support for Column Filter and Sort support for Lookup Columns
