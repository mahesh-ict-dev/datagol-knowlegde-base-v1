**Date released: May 27, 2026**


## Enhancements

### AI
- **Google Drive Connector - Metadata Support:** The Google Drive Connector now includes a dedicated metadata tool that lets the AI answer questions directly about your Drive files — such as how many files exist, who created a specific document, or when a file was last updated. Previously limited to content-based search, the connector can now respond to structural and ownership queries using file metadata including File Name, Record ID, Last Updated Date, and Source URL.

### Roles
- **BI Dashboard Admin:** A new BI Admin role gives designated users company-wide visibility and control over all External Dashboards — including the ability to view, manage access, and remove pages — without requiring explicit sharing.
