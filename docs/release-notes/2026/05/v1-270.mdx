**Date released: May 7, 2026**


## New Features and Enhancements

### AI


- **Support for AWS Bedrock Models:** The Custom Agent now supports AWS Bedrock as a model provider. Users can configure and run agents using Bedrock-hosted models, expanding the available model selection beyond existing providers and enabling teams already invested in the AWS ecosystem to leverage their Bedrock setup directly within the agent platform.
- **Support for Vertex AI Models:** Vertex AI models are now supported as a model provider option within the Custom Agent. This allows agents to be configured to use Google Cloud-hosted models via Vertex AI, broadening the provider landscape and giving teams additional flexibility in model selection based on their infrastructure and preference.
