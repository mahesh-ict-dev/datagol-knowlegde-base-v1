**Date released: May 19, 2026**


## New Features and Enhancements

### Workspaces and Workbooks
- **Tenant Workbook support:** Introduced Tenant Workbook support for secure multi-tenant data sharing, enabling DYNAMIC master workbooks to be published into other workspaces with shared physical storage, automatic tenant-based row filtering and write enforcement, live schema inheritance from the master workbook, async cache synchronization, and restricted schema modification on tenant workbooks.
