## New Features and Enhancements

### AI


- **Agent UX - Updated Landing Page Design:** The AI Space landing page has been refreshed with an updated visual design, improving the overall presentation and first-impression experience when users enter the AI Space.
- **Codex Agent:** Prior Thread Data Shown in UI The Codex agent UI now surfaces prior thread data, allowing users to view historical conversation context directly within the interface. This improves continuity across sessions and reduces the need to re-establish context when returning to an ongoing Codex workflow.
