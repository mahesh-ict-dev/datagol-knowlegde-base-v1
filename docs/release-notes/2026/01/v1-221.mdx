### Workbooks

#### Reverse ETL via generic HTTP connector

Launched **Reverse ETL** capabilities, which allows you to push workbook data directly back into your external systems. Using our new **generic HTTP connector**, you can automate downstream updates and keep your entire tech stack in sync with your latest analysis.

-   **Universal integration:** Connect to almost any external API without needing specialized plugins.
    
-   **Smart record updates:** Our logic identifies and modifies only changed data points, ensuring faster, more reliable synchronization than full-record overrides.
    
-   **Dynamic endpoint resolution:** The connector automatically injects record IDs from your workbook into destination URLs for precise, individualized updates.
    
-   **Seamless automation:** Trigger data pushes directly from your workbook to keep external tools and databases updated in real-time.
