**Date released: January 15, 2026**

## New features and enhancements 

### AI agents 

#### GRC agent 

Introduced the ability to save GRC agent analysis results directly into a workbook. This update allows you to automate the capture of analysis data into structured rows for easier tracking and reporting.

-   **Pre-analysis destination selection:** You can now configure where your analysis results are stored before the process begins. Choose to save data to an existing workbook or automatically create a new one within your selected workspace.
    
-   **Automated data population:** Once enabled, the GRC agent writes its findings directly into the designated workbook as organized rows and columns, eliminating the need for manual data entry.
    
-   **Streamlined workflow navigation:** After the analysis is complete, the system provides a direct link to the populated workbook, allowing you to move seamlessly from insight to documentation.

#### Agents interface and usability enhancements

Refined the agents interface to improve visual clarity and interaction stability across the chat and exploration flows. These updates resolve several UI inconsistencies to ensure a smoother navigation experience.


-   **Improved navigation stability:** Resolved spacing issues in the side panel to prevent overlapping items during fast scrolling or when expanding conversation threads.
    
-   **Smart capability indicators:** The interface now dynamically shows or hides icons, such as the voice feature, based on the specific capabilities enabled for each agent.
    
-   **Deep Research visibility:** Added clear visual indicators to identify agents with Deep Research enabled, making them easier to distinguish in the agent list and during active chats.
    
-   **Enhanced SQL agent data sourcing:** Search results for the SQL agent now display the associated data source provider, allowing for immediate identification of where the data originates.
    
-   **Cleaner interface logic:** Context menus and action buttons are now hidden when no options are available, reducing UI clutter and preventing non-functional interactions.

### Data Source

#### Fellow custom connector support

-   Introduced a new data source option with the Fellow custom connector. This expansion allows you to integrate and pull data from Fellow directly into your environment for broader analysis and reporting.
