## New features and enhancements 

### AI agents 

Enhanced the DCA and SQL agent workflows by allowing queries to be published directly as workbooks, exported as CSV, or opened in the visualizer. To ensure complete data access, query limits are automatically removed when publishing from these surfaces.

### Orchestration 

#### Orchestration UI/UX enhancements

Redesigned the orchestration interface to provide a more intuitive and user-friendly experience. These updates simplify workflow management and improve overall usability when navigating complex processes.
