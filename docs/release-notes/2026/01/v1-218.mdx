**Date released: January 14, 2026**

## New features and enhancements 

### AI agents 

#### Custom agent

Introduced public sharing for Custom Agents, allowing external users to interact with your agents via a secure, shareable link without requiring a login. This update also includes enhanced styling options and new interactive document tools to improve the research experience.

-   **External public access:** You can now generate a public link for any Custom Agent, enabling guests to chat with the agent while ensuring they only access documents scoped to the agent's specific workspace.
    
-   **Agent branding and styling:** New customization options allow you to upload a unique logo and adjust background and text colors, giving your Custom agents a distinct look and feel.
    
-   **Integrated document viewer:** A new side panel provides immediate access to the documents powering your RAG and Custom agents, ensuring you can quickly reference the source material used for agent responses.
    
-   **Interactive PDF tools:** When viewing PDFs, you can now highlight specific text to trigger the "Ask AI about this" feature, using the selected content as direct context for more precise follow-up questions.

#### GRC agent

Updated the GRC agent evaluation process to allow for custom export destinations. You can now select a specific workspace and workbook to receive your GRC evaluation data, ensuring your compliance results are organized exactly where you need them.

#### RAG based agents 

Improved the citation system for RAG-based agents to include specific page numbers within the responses. This update allows for more precise verification of sources by linking answers directly to the relevant sections of your documents.

-   **Page-level citations:** Agent responses now include exact page numbers for all cited sources, providing greater transparency and accuracy for generated answers.
    
-   **Direct document navigation:** Clicking a citation now takes you directly to the specific page used to generate the answer, rather than just the start of the document, making it easier to review supporting evidence.
