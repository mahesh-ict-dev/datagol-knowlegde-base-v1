## New features and enhancements 

### Backend

-   Optimized data retrieval for static tables by enabling direct access to the Excel download API, bypassing slower processing steps. This allows for the efficient export of large datasets up to 1,000,000 rows when working with source-powered tables.
-   Expanded backend compatibility to allow analytics widgets to source data directly from Snowflake. This ensures that your charts and visualizations reflect Snowflake data accurately with seamless integration.
