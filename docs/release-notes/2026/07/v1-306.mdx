**Date released: July 21, 2026**

## Enhancements


### AI
- **Skill Management Experience Improved:** Creating, editing, and importing Custom Agent skills is now smoother: skill names are auto-formatted to meet naming conventions, duplicate names trigger a rename suggestion, and you'll be prompted to save unsaved changes before navigating away.

## Bug Fixes
- Resolved an error that caused Custom Agents configured with many MCP integrations to fail entirely due to exceeding the model's 128-tool limit. A smart tool-selector now activates automatically when needed, routing each query to the most relevant tools — without adding latency for smaller configurations.
