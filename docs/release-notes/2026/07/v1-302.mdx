**Date released: July 10, 2026**

## Enhancements
### AI
- **D.A.V.E. Now Supports Analysis Across Multiple Workbooks:** You can now select two or more workbooks in a single D.A.V.E. conversation and ask questions across all of them at once, instead of being limited to one workbook per session. This makes it easier to compare, combine, and analyze data that lives in different workbooks without starting a separate conversation for each one.
