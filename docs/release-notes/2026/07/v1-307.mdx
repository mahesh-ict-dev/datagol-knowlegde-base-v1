**Date released: July 21, 2026**

## Enhancements

### AI
- **Confluence Connector for Knowledge Base:** You can now connect Confluence as a Knowledge Base source. Sync entire spaces or individual page URLs, and your AI agents will be able to search and answer questions against indexed content. Full and incremental syncs are supported.
<ImagePopup src="/img/knowledge-base-connectors/confluence-add.png" alt="confluence add" caption="confluence add" />

### Lakehouse

- **Fathom Data Source Connector:** Fathom is now available as a data source, letting you sync meeting recordings, transcripts, summaries, and action items directly into your pipelines via API key — consistent with the existing Granola and Fireflies integrations.
<ImagePopup src="/img/knowledge-base-connectors/fathom-ds.png" alt="fathom ds" caption="fathom ds" />
