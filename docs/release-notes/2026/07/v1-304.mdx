**Date released: July 15, 2026**

## Enhancements


### Lakehouse
- **Fireflies & Granola Data Source Connectors:** You can now connect Fireflies and Granola as data sources to automatically sync meeting transcripts and notes into your pipelines — no more manual exports. Both connectors support incremental sync and are available under Data Sources.

### Workspaces & Workbooks
- **Updated Field-Type Icons (Abc / # / Globe):** Field icons in the Tables panel, chart builder, and filters now use industry-standard conventions: Abc for text fields, # for numeric fields, and a globe icon for geographic fields. This makes workbook schemas faster to scan for users familiar with Tableau or Looker.

## Bug Fixes

- Resolved an issue where scheduled Custom Agent executions were failing to run and not producing any output thread. Agents now execute reliably at their configured schedule time.
