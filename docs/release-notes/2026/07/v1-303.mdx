**Date released: July 14, 2026**

## Enhancements
### AI

- **Stop Button Now Reliably Cancels Streaming Agent Responses:** Fixed an issue where pressing Stop had no effect after a page refresh while an agent was still generating a response. The agent now stops immediately, even when the stream was restored across a refresh.

### Workspaces & Workbooks
- **Inline Record Linking from Expanded View:** You can now create and link new records directly from the expanded row view without leaving your current context. Whether adding a linked record that doesn't exist yet or editing an existing one, everything happens inline — no more navigating away, creating the record elsewhere, and finding your way back.
- **Link and Lookup Columns Included in Workbook Exports:** Workbook downloads now include link and lookup columns, so what you export matches exactly what you see on screen. Previously these columns were silently excluded, leaving gaps in downloaded files.
