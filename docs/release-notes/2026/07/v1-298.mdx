**Date released: July 6, 2026**


## Enhancements
### AI
- **Skill Deletion Warning When Agents Are Affected:** Deleting a Skill that is used by one or more Custom Agents now shows a warning modal before proceeding. The modal lists how many agents are affected, names each one, and lets you open them in a new tab for review — so you can make an informed decision before removing a Skill that others depend on. This protection is consistent whether you delete from the Agent Builder or the Skills library.
