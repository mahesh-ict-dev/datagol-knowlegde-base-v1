**Date released: February 20, 2026**

## New features and enhancements 

##  Agents

-   Added a rerun code capability to the Python agent, allowing users to re-execute specific logic or scripts instantly without having to re-initialize the entire session or provide new prompts.


## Bug Fixes 

### AI 

-   Resolved an issue where the chat thread titles were uneditable; renaming is now enabled for thread owners and disabled for all other users.

-   Fixed an issue where renaming the Jira Agent chat threads failed to save or update on the UI.

### Agents 

-   Fixed an issue where the stale session cleanup API would trigger an error during execution.

-   Fixed an issue where the Data Provider type (e.g., JDBC, Spark) would spontaneously revert or change in production.
