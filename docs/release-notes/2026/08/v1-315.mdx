**Date released: August 11, 2026**


## Enhancements

### AI

- **Agent & Thread Navigation Redesigned for Scale:** Finding the right agent or conversation is now faster and easier. Thread timestamps are visible at a glance without hovering, pinned agents take up less space with a more compact layout, and starting a new chat requires fewer clicks. Navigation behavior is now consistent across Featured and Custom Agents throughout the platform.
- **Per-Agent Disclaimer Messages:** Admins can now configure a custom disclaimer message for each agent, displayed above "Powered by DataGOL" in the chat. When no custom message is set, a sensible default is shown. Toggle the disclaimer on or off per agent — changes to one agent never affect any other.
- **Featured Agent Settings Aligned with Custom Agent Builder:** The settings page for Featured Agents now matches the design and layout of the Custom Agent Builder, creating a consistent configuration experience across all agent types.
