**Date released: August 10, 2026**


## Enhancements

### AI
- **Workbook Agent:** A dedicated Workbook Agent is now available, enabling natural-language interaction directly with your workbook data for a faster, more intuitive way to explore and act on your information.
- **OrchX:** OrchX is now available, bringing orchestration capabilities to coordinate complex, multi-step workflows across your data and agents.



## Bug Fixes

- Fixed an issue where attached files were invisible to the agent — the model would report that no file was provided even when one had been uploaded. Attachments are now surfaced correctly in the agent's context, and the tools that read attached files work as expected.
