**Date released: March 24, 2026**


## New Features and Enhancements
### Lakehouse
- **Slack integration now retrieves all channel types:** After connecting your Slack account, DataGOL now retrieves public channels, private channels, and external Slack Connect channels.
- **Fellow connector — Super Admin mode:** Added a **Super Admin** toggle when setting up the Fellow connector. When enabled, DataGOL retrieves meeting and transcripts data on behalf of all users in the workspace, giving admins a complete view across the entire organization.

### Workbooks
- **Workbook — Convert linked columns to manual relations:** Linked columns can now be converted to manual relations, with all existing matched record pairs automatically carried over. Supports one-to-one, one-to-many, and many-to-many relation types with no data loss during conversion.

- **Workbook — Improved lookup column interactions:** Lookup columns now behave consistently with link columns. A **+** button appears on hover, allowing users to create and attach new links directly from the lookup cell without navigating away from the current view.
