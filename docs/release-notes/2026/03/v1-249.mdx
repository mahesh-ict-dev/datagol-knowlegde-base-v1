**Date released: March 31, 2026**


## New Features and Enhancements

### AI

- **Charts and Dashboards Now Available in Custom Agent:** The Frontend Design Skill has been integrated into the Custom Agent, allowing users to generate charts and dashboards directly from their queries for instant visual data insights.
- **Stop a Running Agent Mid-Execution:** Users can now cancel an active agent mid-processing, which immediately halts execution and readies the agent to accept a new question.
- **Improved Responsiveness of Frontend Skills in Custom Agent:** Performance and layout improvements now make frontend skills render faster and more reliably in the Custom Agent, with added support for more customized skills to boost agent intelligence and flexibility.
- **More Precise Confluence Permissions for the Atlassian Agent:** The Atlassian Agent now uses fine-grained Confluence permission scopes, ensuring it only requests the specific access it needs — improving security and reducing unnecessary permissions.
- **See Non-Compliant Details Directly in the Workbook:** The GRC Agent now displays non-compliant content chunk details directly in the workbook during compliance checks, giving users clear visibility into exactly what failed and why.
- **New AI Model Available: OpenAI GPT-5.4:** OpenAI's latest model, GPT-5.4, is now available on the platform and can be selected when configuring agents or queries.

### Workspaces & Workbooks

- See linked records across all lookup columns in one unified view
- Link two workbooks across different workspaces seamlessly
- Experience consistent search behavior in expanded popups, just like in workbooks
- Copy, paste, and bulk add options for single select and multi-select fields
- Add AI-generated logic directly to static columns
- Prevent duplicate selections by disabling already-added fields when creating new lookup columns



## Bug Fixes
- **Index Settings Crash on Unconfigured Workbook**Resolved an issue where opening Index Settings on an unconfigured workbook caused the system to error out — the settings page now loads correctly in all states.
