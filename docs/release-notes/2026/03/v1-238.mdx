### Simplified Custom agent creation flow

Streamlined the **agent creation** process to provide a more intuitive experience. By focusing the initial setup on core requirements and moving advanced configurations to a separate view, users can now build and deploy agents with significantly less friction.
This change balances accessibility for new users with the granular control required by power users, ensuring the platform remains powerful without feeling overwhelming.

-   **Streamlined primary setup:** The main creation interface now prioritizes essential fields, allowing for a faster "quick-start" workflow.
    
-   **Dedicated advanced options screen:** To reduce cognitive load, technical configurations have been relocated to a secondary **Advanced options** screen.
    
-   **Improved visual hierarchy:** Decluttered the interface to help users focus on the most impactful settings first, ensuring a smoother onboarding path for new users.
