**Date released: March 26, 2026**


## New Features and Enhancements

### AI

- **Removed Basic Authentication for Atlassian Connector:** Basic Authentication (username/password) has been removed as a login option for the Atlassian connector. OAuth 2.0 is now the sole supported authentication method, ensuring a more secure setup process.

- **Document Indexing Status Filter – Workspace:** Added a new filter to the Documents tab that lets you quickly identify documents that haven't been indexed yet. You can now see exactly what's still being processed and what's AI ready — giving you full visibility into your document indexing status at a glance.


### Onboarding

- **Faster, Simpler Onboarding with OTP Verification:** The account creation flow has been redesigned to reduce friction and get users to value faster. The previous multi-field form and email hash link verification have been replaced with a streamlined OTP-based signup — just enter your email and password, verify with a one-time code, and you're in. A short optional profile step lets you personalize your experience without blocking access.


## Bug Fixes

- Fixed an issue where citation links in Custom and RAG agent responses failed to open the referenced workspace document. Users can now click any citation to navigate directly to the source, making it easier to verify information and build confidence in agent responses.
