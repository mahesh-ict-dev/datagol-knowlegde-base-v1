**Date released: March 11, 2026**


## New Features and Enhancements

### AI

- **Revamped Explore Page** The Explore page has been redesigned to improve agent discoverability and help users find the right agent faster. Key improvements include:
  - **Category Filters** — Browse agents by capability using quick filter buttons (e.g., Advanced Reasoning, Intelligence & Search, Analytics & Insight, Integration & Action, Custom).
  - **Search Support** — Find agents instantly using the new search input.
  - **About this Agent Modal** — Click to open a detailed description of each agent's capabilities and recommended use cases, keeping the card UI clean and uncluttered.
  - **Improved Agent Card Layout** — Refreshed presentation for a cleaner, more scannable experience.

- **Simplified Custom Agent Interface** - Workbook, Data Source, and Workspace dropdowns have been removed to reduce clutter. Users can now add context or resources using the universal “+” button, creating a cleaner and more intuitive workflow across all agents.

### Onboarding
- **Guided Onboarding Tour** A step-by-step product tour now automatically launches for first-time users upon entering the platform, helping them quickly understand core features and get to their first interaction faster. Key improvements include:
  - **Guided UI Walkthrough** — The tour highlights key areas of the interface, including Workspaces and Documents, to help new users orient themselves quickly.
  - **Agent Introduction** — Agents are introduced as a primary interaction point, with contextual guidance on where and how to use them.
  - **First Question Prompt** — The final step of the tour encourages users to ask their first question, enabling them to immediately experience the core value of the platform.
  - **Ask from Home Page** — Users can now ask questions directly from the home page without navigating to another section.
  - **Skippable Tour** — Users can exit or skip the tour at any point if they prefer to explore independently.
