## New features and enhancements

### AI

Refined how workbooks are displayed within the LLM settings to ensure a more intuitive user experience when handling shared resources.

-   **Improved workbook display logic** Previously, when an agent was shared but the associated workbook was not, the system would display the technical **Workbook ID** in the LLM settings. This often caused confusion for users who were not familiar with internal ID strings.
    
-   **Enhanced user clarity** The interface now provides a clearer state or fallback name, ensuring that users can identify their configuration context without needing to parse raw identification data.
