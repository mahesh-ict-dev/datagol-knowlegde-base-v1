## New features and enhancements 

## AI Agents 

### Deep research for Custom agents

Enhanced the custom agent feature by introducing deep research capabilities. This improvement allows agents to gather, analyze, and synthesize information from multiple sources to quickly provide clear, well-supported conclusions.

-   **Deep research toggle:** A new setting allows you to enable deep research for any custom agent. When active, the agent can utilize specialized sub-agents to perform more comprehensive data gathering and analysis.
    
-   **Sub-agent configuration:** You can now configure and manage multiple sub-agents within a single custom agent. These sub-agents work in parallel to handle specific tasks, ensuring more thorough research results.
    
-   **Enhanced execution transparency:** A new activity panel in the chat interface provides real-time visibility into the research process. You can monitor the status of tasks, track sub-agent progress, and view structured checklists as the agent works toward a conclusion.
    
-   **Streamlined research workflows:** The system ensures all sub-agents are properly configured before saving, guaranteeing that your deep research agents are always ready to deliver high-quality insights.

## Bug Fixes

### AI

#### Message Management

Resolved an issue where users could not delete messages in the active chat thread without a page refresh. Deletion is now available immediately after an AI response. 
Users can now delete messages associated with **cancelled** or **failed** requests.
