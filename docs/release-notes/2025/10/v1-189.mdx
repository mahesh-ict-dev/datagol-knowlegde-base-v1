**Date released: October 16, 2025**

## New features and enhancements

The following new features are included in this release:

### AI Agents

-   **Voice Agent UI** is integrated into the **Help** section, providing a new way to interact and get assistance.
    

**Lakehouse/Workbook/Workspace**

**Instant "Copy Link" for entity sharing:** Enhanced the user experience when sharing assets across the platform by introducing a **Copy Link** option, similar to what you may be familiar with in applications like Google Drive. This feature simplifies collaboration and improves navigation by allowing users to instantly copy a direct, shareable URL to any supported entity.

When initiating the sharing process for any supported entity (e.g., via the share icon or context menu), users will now see a dedicated **"Copy Link"** button alongside the traditional sharing methods. Clicking this button immediately copies the entity's direct URL to the user's clipboard, ready to be pasted into emails, chat messages, or documentation.

This enhancement has been implemented across the following areas in DataGOL platform:

-   **Lakehouse**
    
-   **DataSources**
    
-   **Pipelines**
    
-   **Orchestration**
    
-   **Dashboards**
    
-   **Workspaces**
    
-   **Agents page**
