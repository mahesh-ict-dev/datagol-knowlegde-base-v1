**Date released: October 11, 2025**

## New features and enhancements

The following new features are included in this release:

### AI Agents

**Share agent threads with a public link:** This release introduces the ability to share threads directly from the Agents page, allowing for easier collaboration and review of agent conversations. This feature simplifies the process of reviewing and sharing agent interactions with others, without requiring them to log into the platform.

-   **Public link sharing:** The user who owns a specific agent thread can now generate a public link for that thread.
    
-   **Access thread history:** Anyone with the shared public link can view the complete thread history of the agent conversation.

## Bug fixes

The following bug fixes are included in this release:

### AI Agent

**Thread access control fix:** Previously, any user could access and view the contents of a thread simply by knowing its thread ID. In this release, strict access control checks are implemented for thread IDs. Now, a user must be explicitly authorized to view a thread's content, preventing unauthorized access via known IDs.
