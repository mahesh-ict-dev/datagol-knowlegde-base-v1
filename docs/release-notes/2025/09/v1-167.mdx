**Date released: September 9, 2025**

### New features and enhancements

The following new features and enhancements are included in this release:

#### Workbooks

**Custom columns for static workbooks:** Static tables that have been converted from S3 to a database now support the addition of custom columns. When you add a new column, the table type will automatically change from static to hybrid, giving you more flexibility and control over your data. You can now add normal columns as well as formula columns to your static workbooks.
