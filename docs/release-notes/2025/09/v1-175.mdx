**Date released: September 23, 2025**

## New features and enhancements

### Workbooks

**Link and lookup support for hybrid tables:** Provided added support for Link and Lookup columns.

-   **Enabling relational joins:** Users can now define Link and Lookup columns on hybrid tables, making lookup fields from the referenced tables visible and selectable.
    
-   **Link preservation:** Existing link/lookup definitions will now persist across pipeline reruns, ensuring stability in your relational schema.
    
-   **Formula compatibility:** Formula columns that reference linked fields will continue to function as expected, with no change in current behavior.
