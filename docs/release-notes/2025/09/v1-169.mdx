**Date released: September 11, 2025**

### Bug Fixes

The following bug fixes are included in this release:

**Google sign-in:** A problem was resolved where a new workspace was created every time a user signed in with their Google account.

The system now correctly publishes the event to create a default workspace only during the initial account creation. Subsequent sign-ins will not create extra workspaces.
