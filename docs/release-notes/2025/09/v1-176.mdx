**Date released: September 23, 2025**

## New features and enhancements

### AI Agent - Python

Added a helpful new feature to streamline how you analyze visual data presented by the agent.

When the agent responds with a generated graph or chart, you will now see a dedicated button labeled **"Ask about this chart."**

-   **How it works:** Simply click this button to instantly prompt the agent for details and analysis specific to that visualization.
    
-   **Benefit:** This eliminates the need to manually reference the chart (e.g., "tell me about plot1") and provides a faster, more contextual way to drill down into your data insights.
