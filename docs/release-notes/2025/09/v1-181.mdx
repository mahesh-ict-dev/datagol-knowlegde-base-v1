**Date released: September 29, 2025**

## New features and enhancements

### AI Agents

#### **Finance Deep Research agent**

Introduced the **Finance Deep Research (FDR)** agent, which is a powerful multi-agent system designed to deliver comprehensive financial analysis.

This agent uses a collaborative network of specialized sub-agents (e.g., Cash & Liquidity, Current Liability, Revenue Growth, Gross Profit specialists) that independently access real-time internet data.

The FDR agent provides the following benefits:

-   **In-depth financial analysis:** Ask for a financial analysis on any organization (e.g., "Help me with the financial analysis of [Company Name]").
    
-   **Multi-faceted research:** The agent breaks down the task into sub-tasks (e.g., cash and liquidity, current assets, current liabilities, debt structure, revenue analysis, gross profit margin) and utilizes specialized tools for each.
    
-   **Comprehensive report:** Generates a full report including an executive summary, detailed analysis of key financial areas, risk assessment, overall outlook, and investor-specific key items.ß
