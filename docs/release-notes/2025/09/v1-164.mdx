**Date released: September 2, 2025**

## New features and enhancements

The following new features and enhancements are in this release:

### AI

**Improved API key configuration for LLM providers:** The AI application's infrastructure has been enhanced to streamline API key management for LLM providers. Now, the application can retrieve company-level configurations or virtual keys directly from the central company config. This change simplifies communication with different LLM providers, improving efficiency and centralizing key management.
