**Date released: September 16, 2025**

### New features and enhancements

#### Dashboard

-   **Dashboard page reordering:** You now have the flexibility to reorder pages within your dashboards. While pages are sorted alphabetically by default, any changes you make to the order will be saved as your personal preference.
    
-   **Duplicate dashboard:** You can now easily duplicate dashboards from the settings panel within each workspace. When you create a duplicate, the order of all widgets will be maintained.  
    The new dashboard will also copy over all page-level and widget-level filters, as well as any include/exclude filters you have set on individual widgets.
    

#### Workbooks

-   **Enhanced table summaries:** You can now get quick statistical summaries for numeric columns directly within the table widget. A new section has been added to the bottom of tables to display summary metrics like **average, sum, minimum, maximum,** and **median**.  
    This enhancement allows you to select which summary statistics to display for each numeric column. The selections can be configured from both the visualizer and dashboards and will be saved as your user preference, making it easier to get the insights you need at a glance.
