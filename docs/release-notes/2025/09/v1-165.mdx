**Date released: September 4, 2025**

### New features and enhancements

The following new features and enhancements are in this release:

#### Workbook

**Improved workbook query builder:** The workbook query builder has been enhanced to let you edit existing query configurations. You can now open a previously built query, make changes to selected tables, joins, and columns, and then save those updates. The system will also provide clear notifications if any join conditions are impacted by deleted columns, which helps prevent failed reports. After saving, the report will refresh with the new query results.
