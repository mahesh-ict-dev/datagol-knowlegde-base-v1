**Date released: November 7, 2025**

## New features and enhancements 


### Workspace

Addressed multiple UI issues on the **Documents** page to ensure **reliable file uploads** and **consistent file previews**. These fixes significantly enhance the stability and usability of the document management system.

-   **Enhanced upload stability and concurrency:** Uploads are now limited to a maximum of 10 concurrent requests to prevent backend overload and intermittent upload failures when handling large folders.
    
-   **Resolved folder path conflicts:** Improved path resolution allows uploads to succeed consistently, even when different subfolders share the same name (e.g., `/A/common/` and `/B/common/`).
    
-   **Case-insensitive file preview:** File extension handling is now case-insensitive, ensuring previews load correctly regardless of whether the extension is uppercase or lowercase (e.g., .PDF, .mp4).

### Agents

Resolved critical issues on the **Agents** page related to thread navigation and sharing, ensuring a consistent and reliable user experience.

-   **Fixed inconsistent thread opening:** Clicking certain existing threads failed to load or open them. Audited and corrected the navigation logic to ensure the correct thread ID is passed, and the UI state updates immediately upon selection. Clicking any thread now reliably opens the correct conversation.
    
-   **Corrected invalid share URLs:** Certain generated share URLs were incorrect or incomplete. The share URL builder logic has been fixed to ensure all shared links consistently include the necessary agent ID and thread ID, routing users to the exact thread content.
