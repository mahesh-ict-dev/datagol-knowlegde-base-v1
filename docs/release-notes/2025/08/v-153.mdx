**Date released: August 9, 2025**


## New features and enhancements

The following new features and enhancements are in this release.

### Data Sources

DataGOL now offers a **Mailchimp** connector, enabling seamless integration of data from your Mailchimp account into the data warehouse. This integration:

-   **Centralizes marketing data:** Consolidate your Mailchimp campaign, audience, and performance data with other business data sources for a unified view.
    
-   **Enhances analytics:** Perform advanced analysis by combining Mailchimp data with insights from your CRM, e-commerce, and other platforms.
    

### Backend

-   When a new user accepts an invitation to join a team, they will now be automatically accepted into all pending workspace invitations associated with that team.
    
-   Provided an internal API for AI to upload images to S3.
    
-   You can now test your AI extraction prompts on a per-column basis directly against an uploaded document. This enhancement allows for live verification of prompt accuracy, helping you fine-tune your settings before running a full extraction.
    
    -   **Individual column testing:** Test the extraction prompt for a single column against a real document.
        
    -   **Live document preview:** See a preview of the uploaded document adjacent to the extraction results for easy reference.
        
    -   **Instant results:** Get instant feedback on your prompt's performance to quickly verify accuracy.
        
    -   **Pre-run validation:** Ensure your prompts are correctly configured before committing to a full-scale extraction, saving you time and effort.
        

### Email campaign

**Subject line parameterization**: You can now add parameters directly into your email campaign subjects. These parameters will automatically populate with multiple values, allowing for more dynamic and personalized subject lines without manual updates.

## Bug Fixes

This release contains the following bug fixes:

### Backend

Improved security by **implementing email encoding** for the reset password URL. This enhances the protection of user data and ensures a safer password recovery process.
