You can change the underlying data source of a dashboard from one workbook to another.

:::warning [CAUTION]
Before switching dashboards to a new workbook, it's crucial to ensure the new workbook is compatible to prevent errors.

This involves verifying that the **column names and data types** in the new workbook are consistent with the previous one. The application often flags discrepancies like incorrect names or data types with an error indicator, requiring correction before the new workbook is attached.

This proactive check ensures a smoother transition and that the dashboard functions as expected with the updated data source.

Do the following to switch workbooks in a dashboard:

1.  From a workspace, access a dashboard.
    
2.  On the dashboard, from the upper right corner, click settings and then choose **Switch Workbooks**. The Switch Workbooks box is displayed.
    
    <ImagePopup src="/img/visualizer/image-20250504-183842.png" alt="switch-workbooks-in-a-dashboard" caption="switch-workbooks-in-a-dashboard" />
    
3.  Select the existing workbook and the workbook you want to replace.
    
     <ImagePopup src="/img/visualizer/image-20250504-184035.png" alt="switch-workbooks-in-a-dashboard" caption="switch-workbooks-in-a-dashboard" /> 
    
4.  Click **Save**.
