The **External Dashboard** provides a centralized location for accessing critical dashboards from across the platform and a space for users who need a high-level overview of key metrics.

1.  From the **Home** page, from the left panel, click **Dashboards**.
    
2.  From the top right corner, click **New Dashboard**.
    
3.  In the **Create Dashboard** box, provide a name and description for the dashboard.
    
4.  Specify a color for the dashboard and click **Create**.
    
5.  From a dashboard which is well compiled dashboard with widgets, from the upper right corner, click settings icon.
    ![switch-workbooks-in-a-dashboard](/img/visualizer/image-20250504-174948.png)
    
6.  Click the **Pin to Dashboard/Interface** option.
    
7.  In the **Pin to Dashboard/Interface** box, select the newly created dashboard.
    
8.  Click **Confirm**.
