To create a dashboard, do the following: 

1.  Access a workspace and click **Dashboard** tab from the top.

    <ImagePopup src="/img/visualizer/image-20250514-151324.png" alt="create-dashboard" caption="create-dashboard" />

2.  Click **Create Blank page**. The **New Dashboard** page is displayed.
    
3.  Enter a unique name and meaningful description for the dashboard.
    
4.  Click **Create**.
    
5.  After creating a visualization/widget, ensure to save/pin that to a dashboard. The Dashboards are then populated with widgets.
