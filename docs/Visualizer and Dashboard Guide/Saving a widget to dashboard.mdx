## Saving a widget to a dashboard

After you create a widget, ensure to save the widget to a dashboard.

1.  [Create a dashboard.](https://saasxl.atlassian.net/wiki/spaces/documentation/pages/392527873/Data+visualization+-Guide#Creating-dashboards "https://saasxl.atlassian.net/wiki/spaces/documentation/pages/392527873/Data+visualization+-Guide#Creating-dashboards")
    
2.  Create a visualization/widget.
    
3.  From the upper right corner of the widget, click the **Save** button.
    
4.  Select the **Pin to Dashboard** option. The **Pin Visualization to Dashboard** box is displayed.
    
5.  Add a title and subtitle and select the dashboard where you want to save the widget.
    
6.  Click **Pin**. The widget can be accessed from the Dashboard.
