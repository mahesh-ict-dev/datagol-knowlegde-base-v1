## Adding page level/dashboard level filters

1.  From a workspace, access a dashboard.
    
2.  On the dashboard, from the upper right corner, click the **Settings** icon and then choose **Manage filters.**
    
3.  In the **Manage Filters** box, click **New filter**.
    
4.  In the **New Filter** box, specify the following details.
    
    -   **Default**:
        
        -   Select workbook
            
        -   Filter column
            
        -   Value
            
    -   **Applicable to**: Control where your filter is applied to fine-tune your dashboard. Choose whether this filter should apply to some widgets but not others.
        
    -   **Linked filters**: Use a filter from one workbook to filter widgets across multiple workbooks.
        
5.  Click **Apply**.
