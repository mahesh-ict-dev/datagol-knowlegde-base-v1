DataGOL concepts

Lakehouse​

Lakehouse is a data warehouse that combines the best features of data lakes and datawarehouses. It is designed to handle both structured and unstructured data, providing a unified platform for data storage, processing, and analytics. See also:

  • About Lakehouse
  • Lakehouse workflow

Data Sources​

From Data sources you connect and access a wide range of data platforms. This includes databases, data warehouses, data lakes, API’s, and more.

Pipelines​

Pipelines contains a series of processes and steps that are used to extract, transform, and load(ETL) data from its source (data source) to a destination such as a data warehouse, data lake, or another system for analysis and storage.

Data Warehouse​

A data warehouse is a storage system that gathers and organizes large volumes of data from various sources for analytical purposes, such as reporting and data analysis.

Workspaces​

Workspaces are virtual environments or areas within a system or software platform where users can collaborate, organize, and manage their work-related tasks, projects,or data.

Workbooks​

Workbooks are digital documents or files used to organize and analyze data, often containing multiple sheets or tabs with data, formulas, charts, and other elements.

Dashboard​

A dashboard is a visual representation of key performance indicators (KPIs), metrics, and data points that provide a summary view of an organization or system's performance, typically displayed in a graphical format for quick insights.

AI Agent​

AI Agents are virtual assistants enhanced by Artificial Intelligence to boost productivity and efficiency in work settings.

Playground​

Playground is an environment where users can experiment, test and explore the data.
