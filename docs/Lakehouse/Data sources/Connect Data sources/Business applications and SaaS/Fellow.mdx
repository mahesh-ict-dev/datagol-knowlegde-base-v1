# Fellow

## Adding Fellow as data source

Do the following to add Fellow as data source:

1. From the left navigation panel, click **Lakehouse** and then click **Data Sources**.
2. From the upper right corner of the page, click the **+ New Data Source** button to start the process of adding a new database.
3. In the **New Data Source** page, click the **Fellow** icon.
4. Specify the following details to add Fellow. Once you have connected a data source, the system immediately fetches its schema. After this schema retrieval process is complete you can browse and interact with the tables and data.

| Field | Description |
| ------- | ----------- |
| **Connection Name** | Enter a unique name for the connection. |
| **Subdomain** | Enter your Fellow subdomain (e.g., if your workspace is `company.fellow.app`, enter `company`). |
| **API Key** | Specify your Fellow API Key. You can generate this in your Fellow workspace settings under User Settings > API. |
| **Start Date** | Enter the date in the MM-DD-YYYY format. DataGOL will replicate the data updated on and after this date. If this field is blank, DataGOL will replicate data for the last two years. This applies only to incremental streams. |
| **Super Admin Mode** | Toggle this on to retrieve data on behalf of all users in your DataGOL workspace. When enabled, DataGOL will sync meeting and collaboration data across the entire organization. Leave this off to sync only your own data. |
| **DataGOL Service Account Token** | Required when Super Admin Mode is enabled. Enter your DataGOL service account token to authorize organization-wide data retrieval. |

5. Click **Submit**.
