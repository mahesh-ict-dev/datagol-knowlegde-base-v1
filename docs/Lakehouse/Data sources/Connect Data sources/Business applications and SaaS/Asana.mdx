# Asana

## Adding Asana as data source

Do the following to add Asana as data source:

1. From the left navigation panel, click **Lakehouse** and then click **Data Sources**.
2. From the upper right corner of the page, click the **+ New Data Source** button to start the process of adding a new data source.
3. In the **New Data Source** page, click the **Asana** icon.
4. Specify the following details to add Asana. Once you have connected a data source, the system immediately fetches its schema. After this schema retrieval process is complete you can browse and interact with the tables and data.

| Field | Description |
| ------- | ----------- |
| **Connection Name** | Enter a unique name for the connection. |
| **Personal Access Token** | Specify your Asana Personal Access Token. You can generate this in your Asana account under My Profile Settings > Apps > Manage Developer Apps. |

5. Click **Submit**.
