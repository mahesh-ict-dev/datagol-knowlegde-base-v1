# Apple Search Ads

## Adding Apple Search Ads as data source

Do the following to add Apple Search Ads as data source:

1. From the left navigation panel, click **Lakehouse** and then click **Data Sources**.
2. From the upper right corner of the page, click the **+ New Data Source** button to start the process of adding a new data source.
3. In the **New Data Source** page, click the **Apple Search Ads** icon.
4. Specify the following details to add Apple Search Ads. Once you have connected a data source, the system immediately fetches its schema. After this schema retrieval process is complete you can browse and interact with the tables and data.

| Field | Description |
| ------- | ----------- |
| **Connection Name** | Enter a unique name for the connection. |
| **Organization ID** | Enter the ID of your organization (found in the Apple Search Ads UI). |
| **Client ID** | Enter your OAuth Client ID obtained from the Apple Search Ads developer portal. |
| **Client Secret** | Enter your OAuth Client Secret obtained from the Apple Search Ads developer portal. |
| **Timezone** | Select either **UTC** (Coordinated Universal Time) or **ORTZ** (Organization Time Zone). The default is UTC. |
| **Start Date** | Enter the date in the YYYY-MM-DD format. Note: For DAILY reports, the Start Date cannot be earlier than 90 days from today. |

5. Click **Submit**.

## Supported sync modes

* Full Refresh - Overwrite
* Full Refresh - Append
* Incremental - Append
* Incremental - Append + Deduped


## Supported streams

### Base Streams
* campaigns
* adgroups
* keywords

### Report Streams
* campaigns_report_daily
* adgroups_report_daily
* keywords_report_daily
