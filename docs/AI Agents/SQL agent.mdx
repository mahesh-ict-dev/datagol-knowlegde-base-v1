### Starting a session with the SQL agent

To begin using the agent, follow these steps:

* **Selecting a data source:** You can choose **any data source** to connect to your desired database environment.
* **Initiating chat:** Once the data source is selected, you can immediately **get started with a chat** with the SQL agent.

### Using the SQL agent chat

The chat box is your primary interface for generating and executing queries:

* **Generating queries:** Input your request using **natural language**. The agent will translate this into SQL.
* **Running queries:** You can **run the queries directly from the SQL agent chat box** once they are generated.
* **Query intent and display:** The **intent of your query is determined and shown in the display** after you submit it.

### Viewing the analysis and progress

The right panel provides crucial information about the agent's actions and execution status:

* **Checking analysis progress:** An analysis is done on your query, and the **progress is constantly updated in the right panel**.
* **Monitoring execution status:** You can see the **progress of the execution in the execution tab** on the right panel.

### Exploring data and tables

The right panel includes tools for data visibility before and during query execution:

* **Accessing the data explorer:** There is a **data explorer tab** on the right panel.
* **Checking data source and tables:** Use the data explorer tab to **check the data source to the tables** available for querying.

### Optimizing and debugging SQL

The agent's advanced features help ensure the generated SQL is high-quality:

* **Optimizing created SQL:** The agent offers **optimization** capabilities for the SQL it generates.
* **Debugging created SQL:** It also provides **debugging** capabilities for the created SQL.

### Switching the analysis model

You have control over the underlying AI model powering the analysis:

* **Changing the model:** **On the fly you can switch the model for the analysis** and choose a different chat GPT (or similar model).
