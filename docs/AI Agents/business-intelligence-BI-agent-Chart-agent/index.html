Business Intelligence (BI) agent - (Chart agent)

BI or Chart agent allows you to visualize data from structured datasets using various chart types and provides insights through graphical representations of data.

Key features of Chart Agent​

  • Chart Generation: Creates various chart types, including bar charts, pie charts, line graphs, and stacked bar charts.

  • Multiple Y-Axis support: Allows for charts with multiple y-axes to compare different metrics.

  • Filtering display: Displays applied filters to ensure transparency.

  • Data distribution visualization: Can visualize the distribution of data across categories.

  • Time-series analysis: Supports line graphs for visualizing trends over time.

  • Dashboard Visualization Attachment: Enables users to attach visual representations of data to dashboards.

Use Cases​

  • Visualizing data trends and patterns.

  • Creating dashboards and reports.

  • Presenting data in an easy-to-understand format.

  • Comparing different data sets visually.

Limitations​

  • Limited interactivity (cannot directly modify filters within the chart).

  • Does not support all chart types (e.g. maps and geo maps).

User Interaction​

  • Users enter questions specifying the desired chart type and data to visualize.

    • Charts are displayed within the chat interface and can be pinned to a dashboard

    • Displays the applied filters.
