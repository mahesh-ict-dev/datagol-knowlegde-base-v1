Data source lineage shows you all the different pipelines and workbooks that draw data from that specific source.

Data source lineage provides a broader view, focusing on a particular data source and its utilization across the entire DataGOL environment. It reveals:

* All the pipelines that read data from the selected data source, indicating how the data is being ingested and processed in different workflows.
* All the workbooks that ultimately use data originating from this source, showing its impact on reporting and analysis.

To access the Data source lineage, do the following:

1.  Navigate to the Lakehouse section in DataGOL and go to the **Data Sources** page.
2.  Select the specific data source for which you want to view the lineage. This will open the data source **Summary** page.
3.  Click the **View Lineage** button. A graph will be displayed, illustrating all the pipelines and workbooks that consume data from this particular data source. You can see where the data from this source is being written into different warehouses or used in various workbooks.
