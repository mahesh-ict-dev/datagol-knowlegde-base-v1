| Role | Description |
|---|---|
| **Account Admin** | The Account Admin role provides comprehensive control over the entire data platform, allowing for the highest level of administrative tasks.<br/><br/>The Account Admin has the following permissions:<ul><li>**Company Management:** Edit company settings.</li><li>**Lakehouse Management**</li><li>**Data Source Management:** Create, edit, view, and delete data sources.</li><li>**Pipeline Management:** Create, edit, view, and delete pipelines.</li><li>**Job Management:** View jobs</li><li>**Connector Management:** Create, edit, view, and delete connectors.</li><li>**User Management:** Create, edit, view, delete users, and assign roles.</li></ul> |
| **Lakehouse Admin** | The Lakehouse Admin role focuses on managing lake houses and their associated components, excluding company-wide settings and user management.<br/><br/>The Lakehouse Admin has the following permissions:<ul><li>**Lakehouse Management**</li><li>**Data Source Management:** Create, edit, view, and delete data sources.</li><li>**Pipeline Management:** Create, edit, view, and delete pipelines.</li><li>**Job and Alert Management:** View jobs and alerts.</li></ul> |
| **Lakehouse Member** | Lakehouse Member role is designed for users who need read-only access to lake houses and their components.<br/><br/>The Lakehouse Member has the following permissions:<ul><li>**Lakehouse Access:** View lake houses.</li><li>**Data Source Access:** View data sources.</li><li>**Pipeline Access:** View pipelines.</li><li>**Job and Alert Management:** View jobs and alerts.</li></ul> |
| **Copilots Member** | The Copilot Member role provides read-only access to copilots.<br/><br/>The Copilot Member has the following permission:<ul><li>View copilots</li></ul> |
| **Copilot Admin** | The Copilot Admin role is specialized for managing copilots within the data platform.<br/><br/>The Copilot Admin has the following permissions:<ul><li>Create Copilots</li><li>Edit Copilots</li><li>View Copilots</li><li>Delete Copilots</li></ul> |
| **Connectors Admin** | The Connectors Admin role is specialized for managing connectors within the data platform.<br/><br/>The Connectors Admin has the following permissions:<ul><li>**Connectors Management:** Create, edit, view and delete connectors</li></ul> |
| **Connectors Member** | The Connectors Member role provides read-only access to connectors.<br/><br/>The Connectors Member has the following permissions:<ul><li>View Connectors</li></ul> |
| **User Admin** | The User Admin role focuses on user administration, allowing for comprehensive user management across the platform.<br/><br/>The User Admin has the following permissions:<ul><li>**User Management:** Create, edit, view, delete users, and assign roles.</li></ul> |
| **User** | The User has the following permissions:<ul><li>Create edit view Workspace, Workbook and Dashboard.</li></ul><br/>Users of all types must have access to workspaces to access the workbooks. |
