# Alerts API Documentation

## Overview

The Alerts API provides comprehensive functionality for managing data alerts, monitoring alert execution history, and handling notification history. The API is organized into three main controllers:

- **AlertController** - Core alert management (CRUD operations)
- **AlertHistoryController** - Alert execution history and statistics
- **AlertNotificationHistoryController** - Notification history and management

## Base URLs

- **Alerts**: `/alerts/api/v1`
- **Alert History**: `/alerts/history/api/v1`
- **Alert Notifications**: `/api/v1/alerts/notification-history`

## Authentication

All endpoints require JWT authentication via the `s_jwt` security requirement.
