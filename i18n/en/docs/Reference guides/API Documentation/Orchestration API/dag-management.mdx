# DAG Management API

The DAG Management API provides endpoints for creating, reading, updating, and deleting Directed Acyclic Graph (DAG) workflows.

## Get All DAGs

**Endpoint:** `GET /orchestration/api/v1/dags`

Retrieves all DAGs accessible to the user.

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `pipelineId` | List&lt;Long&gt; | No | Filter DAGs by pipeline IDs |

### Response

```json
{
  "data": [
    {
      "id": 1,
      "name": "Data Processing Workflow",
      "companyId": 123,
      "createdAt": "2024-01-15T10:30:00Z",
      "createdBy": {
        "id": 456,
        "email": "user@example.com"
      },
      "nodes": [],
      "edges": [],
      "scheduleType": "MANUAL"
    }
  ]
}
```

### Example Request

```bash
curl -X GET "https://api.saasxl.com/orchestration/api/v1/dags" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## Create DAG

**Endpoint:** `POST /orchestration/api/v1/dags`

Creates a new DAG workflow.

### Request Body

```json
{
  "name": "Data Processing Workflow",
  "scheduleType": "SCHEDULED",
  "schedule": {
    "basicSchedule": {
      "timeUnit": "HOUR",
      "units": "24"
    }
  },
  "defaultParameters": {
    "sourceTable": "raw_data",
    "targetTable": "processed_data"
  },
  "metadata": {
    "description": "Daily data processing workflow"
  }
}
```

### Response

```json
{
  "id": 1,
  "name": "Data Processing Workflow",
  "companyId": 123,
  "createdAt": "2024-01-15T10:30:00Z",
  "createdBy": {
    "id": 456,
    "email": "user@example.com"
  },
  "scheduleType": "SCHEDULED",
  "schedule": {
    "basicSchedule": {
      "timeUnit": "HOUR",
      "units": "24"
    }
  }
}
```

### Example Request

```bash
curl -X POST "https://api.saasxl.com/orchestration/api/v1/dags" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Data Processing Workflow",
    "scheduleType": "SCHEDULED",
    "schedule": {
      "basicSchedule": {
        "timeUnit": "HOUR",
        "units": "24"
      }
    }
  }'
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `dagId` | Long | Yes | The DAG ID |

  "createdBy": {
    "id": 456,
    "email": "user@example.com"
  },
  "nodes": [
    {
      "id": 101,
      "dagId": 1,
      "pipelineId": 789,
      "metadata": {
        "description": "Data extraction pipeline"
      }
    }
  ],
  "edges": [
    {
      "id": 201,
      "dagId": 1,
      "fromNodeId": 101,
      "toNodeId": 102,
      "metadata": {
        "condition": "success"
      }
    }
  ],
  "latestRun": {
    "id": 301,
    "status": "COMPLETED",
    "startTime": "2024-01-15T10:00:00Z",

### Example Request

```bash
curl -X GET "https://api.saasxl.com/orchestration/api/v1/dags/1" \

```

## Update DAG

**Endpoint:** `PUT /orchestration/api/v1/dags/{dagId}`

Updates an existing DAG.

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `dagId` | Long | Yes | The DAG ID |

### Request Body

```json
{
  "name": "Updated Data Processing Workflow",
  "scheduleType": "CRON",
  "schedule": {
    "cronExpression": "0 0 2 * * ?"
  },
  "defaultParameters": {
    "sourceTable": "raw_data_v2",
    "targetTable": "processed_data_v2"
  }
}
```

### Example Request

```bash
curl -X PUT "https://api.saasxl.com/orchestration/api/v1/dags/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Data Processing Workflow",
    "scheduleType": "CRON",
    "schedule": {
      "cronExpression": "0 0 2 * * ?"
    }
  }'
```

## Delete DAG

**Endpoint:** `DELETE /orchestration/api/v1/dags/{dagId}`

Deletes a DAG and all its associated data.

### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `dagId` | Long | Yes | The DAG ID |

### Example Request

```bash
curl -X DELETE "https://api.saasxl.com/orchestration/api/v1/dags/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## Scheduling Configuration

### Cron Expressions

For `ScheduleType.CRON`, use standard cron expressions:

| Expression | Description |
|------------|-------------|
| `0 0 2 * * ?` | Daily at 2 AM |
| `0 0 */6 * * ?` | Every 6 hours |
| `0 30 9 * * MON-FRI` | Weekdays at 9:30 AM |
| `0 0 0 1 1 ?` | Yearly on January 1st |

### Basic Scheduling

For `ScheduleType.SCHEDULED`, use time units:

| Time Unit | Description | Example |
|-----------|-------------|---------|
| `SECOND` | Execute every N seconds | `{"timeUnit": "SECOND", "units": "30"}` |
| `MINUTE` | Execute every N minutes | `{"timeUnit": "MINUTE", "units": "15"}` |
| `HOUR` | Execute every N hours | `{"timeUnit": "HOUR", "units": "24"}` |
| `DAY` | Execute every N days | `{"timeUnit": "DAY", "units": "7"}` |
| `WEEK` | Execute every N weeks | `{"timeUnit": "WEEK", "units": "2"}` |
| `MONTH` | Execute every N months | `{"timeUnit": "MONTH", "units": "1"}` |
| `YEAR` | Execute every N years | `{"timeUnit": "YEAR", "units": "1"}` |
