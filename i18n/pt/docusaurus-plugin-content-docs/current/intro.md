# Bem-vindo ao Centro de Documentação DataGOL

DataGOL é uma plataforma de Agilidade Empresarial alimentada por IA que reúne Dados, IA e Aplicações sob um mesmo teto. Capacitando cada equipe com ferramentas de dados simples, acessíveis e fáceis de usar que impulsionam o crescimento. A plataforma DataGOL elimina a complexidade, integra-se perfeitamente com sistemas existentes e entrega resultados rápidos e mensuráveis, permitindo que empresas aproveitem o poder dos dados como grandes empresas, sem necessidade de grandes orçamentos ou habilidades especializadas.

Esta página de introdução orienta você para todo o conjunto de documentação e sugere onde começar, seja você um engenheiro de dados conectando fontes, um analista construindo dashboards, ou uma equipe de produto integrando insights alimentados por IA em sua aplicação.

## Primeiros passos sugeridos

- Leia o tópico **Primeiros Passos**. Configure seu primeiro Lakehouse, conecte uma fonte de dados e publique um Workbook em menos de 15 minutos.
  - 🔗 [**Conectar**](</docs/Lakehouse/Data%20sources/About%20Data%20sources>): Reúna dados de qualquer fonte.
  - 🔄 [**ETL, Pipelines e Orquestração**](/docs/Lakehouse/lakehouse-workflow): Orquestre facilmente a ingestão, transformação e movimento de dados.
  - [**Colaborar**](/docs/Workspaces/about-workspace): Conecte-se com sua equipe sem problemas através dos Workspaces.

- Explore o [**Playground**](</docs/Playground/About Playground.mdx>). Execute uma consulta de exemplo e teste o Copiloto SQL.

- Gere um dashboard com IA. Escolha o persona Executivo de Negócios e veja o DataGOL construir KPIs automaticamente.
  - 📊 [**Visualizar**](</docs/BI and Visualizer/about-visualizer>) Criar visualizações BI.
  - 🤖 [**Assistente Pessoal IA**](</docs/AI Agents/about-AI-agents>) Use IA como seu assistente pessoal.

- Inspecione [**Lineage**](</docs/Data Lineage/Data source lineage.mdx>). Abra a aba Lineage em seu Workbook para ver fontes a montante e consumidores a jusante.

- Revise [**Melhores Práticas**](</docs/Best practices.mdx>) antes de ir para produção.

## Quem deve usar estes docs
- Usuários de negócio - para Workbook, Visualizador, Dashboards e insights
- Engenheiros de dados – para conectores, pipelines e automação API
- Analistas e especialistas de domínio – para consultas Playground, visualizações BI e Agentes IA
- Engenheiros ML – para módulo ML, fornecimento de recursos e implantações de modelo
- Desenvolvedores/ISVs – para integração de analytics via Workbook REST API
- Equipes de governança e segurança – para Lineage, controles de auditoria e acesso baseado em funções
