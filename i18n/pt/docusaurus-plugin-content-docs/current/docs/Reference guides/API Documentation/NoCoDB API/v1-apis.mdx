# NoCoDB v1 APIs

## Authentication
All v1 APIs require JWT authentication via the `s_jwt` security requirement.

## Core APIs

### Functions API
**Base Path**: `noCo/api/v1/functions`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Get all available functions |

### Transformation API
**Base Path**: `noCo/api/v1/transformation`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/` | Create transformation |
| `PUT` | `/` | Edit transformation |
| `GET` | `/{id}` | Get transformation by ID |
| `DELETE` | `/{id}` | Delete transformation |
| `GET` | `/user/{userId}` | Get transformations by user |
| `GET` | `/fun` | Get all functions |

### Transformation Executor API
**Base Path**: `noCo/api/v1/transformation/executor/`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/` | Execute transformation |

### Widgets API
**Base Path**: `noCo/api/v1/widgets`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/` | Create widget |
| `POST` | `/multiple` | Create multiple widgets |
| `PUT` | `/{widgetId}` | Update widget |
| `GET` | `/{widgetId}` | Get widget by ID |
| `DELETE` | `/{widgetId}` | Delete widget |
| `POST` | `/tableData` | Get table data by widget |

## Usage Examples

### Creating a Transformation

```bash
curl -X POST "noCo/api/v1/transformation" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Data Transformation",
    "description": "Transform data from source to target",
    "sourceTable": "source_table",
    "targetTable": "target_table",
    "transformationRules": []
  }'
```

### Creating a Widget

```bash
curl -X POST "noCo/api/v1/widgets" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Sales Chart",
    "type": "CHART",
    "config": {
      "chartType": "BAR",
      "dataSource": "sales_table"
    }
  }'
```

### Uploading a CSV File

```bash
curl -X POST "noCo/api/v1/file/upload/csv" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "file=@data.csv" \
  -F "tableName=my_table"
```
