# NoCoDB v2 APIs

## Authentication
All v2 APIs require JWT authentication via the `s_jwt` security requirement.

## Usage Examples

### Creating a Workspace

```bash
curl -X POST "noCo/api/v2/workspaces" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Workspace",
    "description": "A new workspace for data management"
  }'
```

### Creating a Table

```bash
curl -X POST "noCo/api/v2/workspaces/{workspaceId}/tables" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tableName": "Sales Data",
    "description": "Sales data table"
  }'
```

### Adding Rows in Bulk

```bash
curl -X POST "noCo/api/v2/workspaces/{workspaceId}/tables/{tableId}/rows/bulk" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '[
    {
      "name": "Product A",
      "price": 100,
      "category": "Electronics"
    },
    {
      "name": "Product B", 
      "price": 200,
      "category": "Electronics"
    }
  ]'
```
