# Data Models

This section describes the data models used in the Alerts API.

```json
  "sourceType": "string",
  "sourceId": "string",
  "alarmSourceType": "string",
  "companyId": "long",
  "userId": "long",
  "config": {
    "key": "value"
  },
  "elementLinks": [
    {
      "alertId": "string",

  "updatedAt": "date",
```

```json
}
```

## Enums

### ScheduleType

Defines the scheduling types for alerts:

- `CRON` - Cron-based scheduling
- `MANUAL` - Manual execution only
- `SCHEDULED` - Scheduled execution
- `DATA_CHANGE` - Triggered by data changes

### ExecutionStatus

Defines the execution status:

- `SUCCESS` - Execution completed successfully
- `FAILED` - Execution failed
