You can view widget data in different modes and views.

## **Viewing a widget in explore/focus mode**

Click the Explore/Focus icon on the top of a widget to view the widget in explore/focus mode.

<ImagePopup src="/img/visualizer/explore-mode.gif" alt="viewing-widget" caption="viewing-widget" />

## **Viewing/Showing raw data of a widget**

Right click inside a widget and select the **Show raw data** option to view the raw data of a widget.

<ImagePopup src="/img/visualizer/show-raw-full-data.gif" alt="viewing-widget" caption="viewing-widget" />

##   
**Viewing/Showing widget data as table**

Right click inside a widget and select the **Show as Table** option to view the raw data of a widget.

<ImagePopup src="/img/visualizer/show-table.gif" alt="viewing-widget" caption="viewing-widget" />

## **Viewing/Showing point data in a widget**

Right click inside a widget and select the **Show Point Data** option to view the raw data of a widget.

<ImagePopup src="/img/visualizer/show-point-data.gif" alt="viewing-widget" caption="viewing-widget" />
