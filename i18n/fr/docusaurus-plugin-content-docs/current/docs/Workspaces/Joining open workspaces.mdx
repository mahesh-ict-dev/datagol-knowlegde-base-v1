To join open workspaces, do the following:

1.  On the **Home** page, from the left navigation panel, click **Workspace**. The **Workspace** page, listing all workspaces, is displayed.
2.  From the upper right corner, click the **Join** button.

    <ImagePopup src="/img/image-20250512-090606.png" alt="Join workspace button" caption="Join workspace button" />
3.  In the **Join a Workspace** dialog box, you'll see a list of available workspaces that are open for joining.

    <ImagePopup src="/img/image-20250512-092324.png" alt="Join a Workspace dialog box" caption="Join a Workspace dialog box" />
4.  Click **Join** next to the workspace you want to access. You can now use the chosen workspace.
