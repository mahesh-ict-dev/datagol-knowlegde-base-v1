# 欢迎来到 DataGOL 文档中心

DataGOL 是一个由 AI 驱动的业务敏捷性平台，将数据、AI 和应用程序整合在一个屋檐下。为每个团队提供简单、经济实惠且易于使用的数据工具，推动业务增长。DataGOL 平台消除了复杂性，与现有系统无缝集成，并提供快速、可衡量的结果，使企业能够像大型企业一样利用数据的力量，而无需大预算或专业技能。

这个介绍页面为您介绍整个文档集，并建议从哪里开始，无论您是连接数据源的数据工程师、构建仪表板的分析师，还是在应用程序中嵌入 AI 驱动洞察的产品团队。

## 建议的第一步

- 阅读**入门指南**主题。在 15 分钟内启动您的第一个数据湖、连接数据源并发布工作簿。
  - 🔗 [**连接**](</docs/Lakehouse/Data%20sources/About%20Data%20sources>): 从任何源收集数据。
  - 🔄 [**ETL、管道和编排**](/docs/Lakehouse/lakehouse-workflow): 轻松编排数据摄取、转换和数据移动。
  - [**协作**](/docs/Workspaces/about-workspace): 通过工作空间与您的团队连接，无后顾之忧。

- 探索[**游乐场**](</docs/Playground/About Playground.mdx>)。运行示例查询并测试 SQL 副驾驶。

- 使用 AI 生成仪表板。选择业务高管角色，观看 DataGOL 自动构建 KPI。
  - 📊 [**可视化**](</docs/BI and Visualizer/about-visualizer>) 创建 BI 可视化。
  - 🤖 [**AI 个人助理**](</docs/AI Agents/about-AI-agents>) 使用 AI 作为您的个人助理。

- 检查[**血缘**](</docs/Data Lineage/Data source lineage.mdx>)。在您的工作簿中打开血缘选项卡，查看上游源和下游消费者。

- 在推送到生产之前查看[**最佳实践**](</docs/Best practices.mdx>)。

## 谁应该使用这些文档
- 业务用户 - 用于工作簿、可视化器、仪表板和洞察
- 数据工程师 – 用于连接器、管道和 API 自动化
- 分析师和领域专家 – 用于游乐场查询、BI 可视化和 AI 代理
- ML 工程师 – 用于 ML 模块、特征来源和模型部署
- 开发人员/ISV – 用于通过工作簿 REST API 嵌入分析
- 治理和安全团队 – 用于血缘、审计控制和基于角色的访问
