There are two primary ways to download data from your workbooks, each with distinct behaviors:

* **Downloading Raw Excel or CSV:** This option downloads all data exactly as it is stored in the workbook. It does **not** apply any filters, sorting, column arrangements, or visibility settings from your current view.
* **Downloading from a View (Excel or CSV):** This option downloads the data with all current settings applied, including:
    * Filters
    * Sorting preferences
    * Column visibility
    * Column order
