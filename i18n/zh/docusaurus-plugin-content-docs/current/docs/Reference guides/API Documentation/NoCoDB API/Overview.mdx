# NoCoDB API Documentation

## Overview

The NoCoDB API is organized into three main versions:
- **noCoDB v1**: Legacy APIs with basic functionality
- **noCoDB v2**: Enhanced APIs with workspace-based architecture  
- **noCoDB v3**: Latest APIs with advanced BI capabilities

## Base URL Structure

```bash
noCo/api/v1/     # Version 1 APIs
noCo/api/v2/     # Version 2 APIs  
noCo/api/v3/     # Version 3 APIs
```

## Authentication

All NoCoDB APIs require JWT authentication via the `s_jwt` security requirement.
