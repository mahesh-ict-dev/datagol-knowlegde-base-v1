# Alert Management API

The Alert Management API provides core CRUD operations for managing data alerts.

## Create Alert

**POST** `/alerts/api/v1`

Creates a new alert with the specified configuration.

### Request Body

```json
{
  "name": "string",
  "description": "string",
  "status": "string",
  "recipients": ["string"],
  "messageTemplateId": "string",
  "scheduleType": "CRON | MANUAL | SCHEDULED | DATA_CHANGE",
  "cronExpression": "string",
  "sourceType": "string",
  "sourceId": "string",
  "alarmSourceType": "string",
  "config": {
    "key": "value"
  },
  "elementLinks": [
    {
      "elementId": "string",
      "elementType": "string"
    }
  ]
}
```

### Response

Returns an `AlertDTO` object.

## Update Alert

**PUT** `/alerts/api/v1/{alertId}`

Updates an existing alert.

### Path Parameters

- `alertId` (string) - The ID of the alert to update

### Request Body

Same as Create Alert

### Response

Returns an `AlertDTO` object.

## Delete Alert

**DELETE** `/alerts/api/v1/{alertId}`

Deletes an alert.

### Path Parameters

- `alertId` (string) - The ID of the alert to delete

### Response

`204 No Content`

## Get All Alerts

**GET** `/alerts/api/v1`

Retrieves all alerts for the authenticated user.

### Response

Returns a `List<AlertDTO>`.

## Get Alert by ID

**GET** `/alerts/api/v1/{alertId}`

Retrieves a specific alert by ID.

### Path Parameters

- `alertId` (string) - The ID of the alert

### Response

Returns an `AlertDTO` object.

## Activate Alert

**POST** `/alerts/api/v1/{alertId}/activate`

Activates a specific alert.

### Path Parameters

- `alertId` (string) - The ID of the alert to activate

### Response

Returns an `AlertDTO` object.

## Deactivate Alert

**POST** `/alerts/api/v1/{alertId}/deactivate`

Deactivates a specific alert.

### Path Parameters

- `alertId` (string) - The ID of the alert to deactivate

### Response

Returns an `AlertDTO` object.

## Unsubscribe from Alert

**GET** `/alerts/api/v1/unsubscribe`

Unsubscribes a user from alert notifications.

### Query Parameters

- `email` (string, required) - The email address to unsubscribe
- `alertId` (string, required) - The ID of the alert

### Response

```json
{
  "message": "string",
  "unsubscribedCount": "string"
}
```
