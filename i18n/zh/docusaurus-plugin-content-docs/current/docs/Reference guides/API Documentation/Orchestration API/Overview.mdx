# Orchestration API Documentation

## Overview

The Orchestration API provides comprehensive functionality for managing Directed Acyclic Graph (DAG) workflows, pipeline orchestration, and execution tracking. The API is organized into several main controllers:

- **DagController** - Core DAG management (CRUD operations)
- **DagNodeController** - Node management within DAGs
- **DagEdgeController** - Edge/connection management between nodes
- **DagRunController** - DAG execution and run management
- **DagSnapshotController** - Version control for DAG configurations

## Base URLs

- **DAG Management**: `/orchestration/api/v1/dags`
- **DAG Nodes**: `/orchestration/api/v1/dags/{dagId}/nodes`
- **DAG Edges**: `/orchestration/api/v1/dags/{dagId}/edges`
- **DAG Runs**: `/orchestration/api/v1/dags/{dagId}/runs`
- **DAG Snapshots**: `/orchestration/api/v1/dags/{dagId}/snapshots`

## Authentication

All endpoints require JWT authentication via the `s_jwt` security requirement.
