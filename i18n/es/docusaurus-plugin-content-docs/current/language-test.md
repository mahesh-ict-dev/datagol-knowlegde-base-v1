# Página de Prueba de Idioma

Esta página se utiliza para probar la funcionalidad de cambio de idioma.

## Contenido de Prueba

- **Inglés**: This is the English version
- **Español**: Esta es la versión en español
- **Francés**: Ceci est la version française
- **Portugués**: Esta é a versão em português
- **Chino**: 这是中文版本

## Cómo Probar

1. Haz clic en el menú desplegable de idioma en la barra de navegación
2. Selecciona un idioma diferente
3. La página debería recargarse con contenido traducido
4. Verifica que la URL cambie para incluir el código de idioma
