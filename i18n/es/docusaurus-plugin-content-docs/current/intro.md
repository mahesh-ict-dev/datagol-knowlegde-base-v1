# Bienvenido al Centro de Documentación de DataGOL

DataGOL es una plataforma de Agilidad Empresarial impulsada por IA que reúne Datos, IA y Aplicaciones bajo un mismo techo. Empoderando a cada equipo con herramientas de datos simples, asequibles y fáciles de usar que impulsan el crecimiento. La plataforma DataGOL elimina la complejidad, se integra perfectamente con los sistemas existentes y entrega resultados rápidos y medibles, permitiendo a las empresas aprovechar el poder de los datos como las grandes empresas, sin necesidad de grandes presupuestos o habilidades especializadas.

Esta página de introducción te orienta a todo el conjunto de documentación y sugiere dónde comenzar, ya seas un ingeniero de datos conectando fuentes, un analista construyendo dashboards, o un equipo de producto integrando insights impulsados por IA en tu aplicación.

## Pasos sugeridos para comenzar

- Lee el tema **Comenzando**. Configura tu primer Lakehouse, conecta una fuente de datos y publica un Workbook en menos de 15 minutos.
  - 🔗 [**Conectar**](</docs/Lakehouse/Data%20sources/About%20Data%20sources>): Reúne datos de cualquier fuente.
  - 🔄 [**ETL, Pipelines y Orquestación**](/docs/Lakehouse/lakehouse-workflow): Orquesta fácilmente la ingesta, transformación y movimiento de datos.
  - [**Colaborar**](/docs/Workspaces/about-workspace): Conéctate con tu equipo sin problemas desde Workspaces.

- Explora el [**Playground**](</docs/Playground/About Playground.mdx>). Ejecuta una consulta de muestra y prueba el Copiloto SQL.

- Genera un dashboard con IA. Elige la persona Ejecutivo de Negocios y observa cómo DataGOL construye automáticamente KPIs.
  - 📊 [**Visualizar**](</docs/BI and Visualizer/about-visualizer>) Crear visualizaciones BI.
  - 🤖 [**Asistente Personal IA**](</docs/AI Agents/about-AI-agents>) Usar IA como tu asistente personal.

- Inspecciona [**Lineage**](</docs/Data Lineage/Data source lineage.mdx>). Abre la pestaña Lineage en tu Workbook para ver fuentes aguas arriba y consumidores aguas abajo.

- Revisa [**Mejores Prácticas**](</docs/Best practices.mdx>) antes de pasar a producción.

## Quién debería usar estos docs
- Usuarios de negocio - para Workbook, Visualizador, Dashboards e insights
- Ingenieros de datos – para conectores, pipelines y automatización API
- Analistas y expertos de dominio – para consultas Playground, visualizaciones BI y Agentes IA
- Ingenieros ML – para módulo ML, abastecimiento de características y despliegues de modelos
- Desarrolladores/ISVs – para integración de analytics vía Workbook REST API
- Equipos de gobernanza y seguridad – para Lineage, controles de auditoría y acceso basado en roles
